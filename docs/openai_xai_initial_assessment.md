# OpenAI 与 xAI 首轮工具准入评估（2026-09-06）

> 本评估依据审查日期可访问的官方公开资料形成，只适用于所列产品形态。供应商条款、控制台配置和企业合同可能变化；正式处理付费用户照片前，应由负责人核对实际账号、项目设置、订单合同及销售地区要求。

## 1. 执行结论

### OpenAI

- **OpenAI API**：可进入技术验证和企业准入流程；默认仅批准去标识文本，人物图像需完成具体端点、项目数据控制和授权复核后再开放。
- **ChatGPT Business/Enterprise**：可作为人工辅助工作区候选，但必须核实实际工作区方案、成员权限、数据控制和文件功能；不能用个人 ChatGPT 账号处理订单照片。
- **个人 ChatGPT**：不批准处理 Hildors 真实订单素材；可用于不含用户个人信息的通用文案和合成测试。

### xAI

- **xAI API/Enterprise**：可进入技术验证和企业准入流程；默认仅批准去标识文本，人物图像及视频需完成具体能力、ZDR、合同和地区审查后再开放。
- **Grok Business/Enterprise 工作区**：可作为候选，但必须核实实际账号层级、保留策略、成员权限和下载行为。
- **Grok 消费者网页/App/X 入口**：不批准处理 Hildors 真实订单素材；可用于不含用户个人信息的通用创意和合成测试。

以上是 Hildors 的内部风险控制结论，不表示供应商官方认定其消费者产品“不安全”。

## 2. 为什么必须区分消费者产品与企业/API

OpenAI 官方说明，API Platform、ChatGPT Business 和 ChatGPT Enterprise 的业务数据默认不用于模型训练，除非客户明确选择分享；API 默认仍可能产生最长 30 天的滥用监控日志，符合条件的客户可以申请 Modified Abuse Monitoring 或 Zero Data Retention，并且不同端点对 ZDR 的兼容性不同。[OpenAI 企业隐私](https://openai.com/enterprise-privacy/)、[OpenAI API 数据控制](https://platform.openai.com/docs/models/default-usage-policies-by-endpoint)

xAI 官方消费者 FAQ 说明，消费者 Grok 内容可能用于训练，但用户可通过数据控制退出；Private Chat 和业务/企业客户内容有不同处理规则。xAI API 安全文档则说明 API 输入输出不会在未经明确许可的情况下用于训练，默认为审计目的保存 30 天，并提供 ZDR 选项。[xAI 消费者 FAQ](https://x.ai/legal/faq)、[xAI API 安全 FAQ](https://docs.x.ai/developers/faq/security)

因此，不能只登记“我们使用 GPT”或“我们使用 Grok”。必须登记具体产品、账号方案、API 项目、端点、数据控制和合同。

## 3. OpenAI API 初步评估

| 项目 | 官方公开信息摘要 | Hildors 初步结论 |
|---|---|---|
| 训练使用 | API 数据默认不用于训练，除非明确选择分享 | 可接受，但生产项目必须确认没有主动共享 |
| 默认保留 | 滥用监控日志默认最长 30 天；部分功能还会保存应用状态 | 不能宣传为默认零保留 |
| ZDR/MAM | 符合条件的组织可申请；端点兼容性不同 | 人物图像启用前逐端点确认 |
| Responses API | 默认可能保存约 30 天应用状态；`store` 和 ZDR 会影响行为 | 生产调用应明确设置并验证项目策略 |
| 图片端点 | 官方表格显示不同图像模型的 ZDR 资格不同 | 不能把文本端点结论自动套到图片生成 |
| 企业数据 | 业务产品默认不用于训练 | 仍需确认实际购买方案和工作区 |
| 人员访问 | 官方说明在支持、滥用调查及法律合规等有限目的下可由授权人员/受约束承包商访问存储数据 | 用户隐私说明不能承诺“任何人都绝不访问” |
| 输出权利 | 服务条款对输入、输出及第三方权利设有具体条件 | 可进入商用评审，但不等于输出必然无侵权风险 |

主要依据：[OpenAI API 数据控制](https://platform.openai.com/docs/models/default-usage-policies-by-endpoint)、[OpenAI 企业隐私](https://openai.com/enterprise-privacy/)、[OpenAI 服务条款](https://openai.com/policies/service-terms/)、[OpenAI Services Agreement](https://openai.com/policies/services-agreement/)

### 3.1 建议允许场景

- 去标识的需求结构化；
- 标准动作脚本和质检原因归类；
- 不含原图的客服文案草稿；
- 使用合成素材进行图像能力和工作流测试。

### 3.2 附条件场景

- 成年人物角色图像；
- 宠物及商品真实照片；
- 图像编辑和参考图生成；
- 用户成品进入其他 OpenAI 工具或第三方 MCP/连接器。

附加条件：使用公司 API 组织和独立生产项目；确认端点保存行为；关闭主动共享；使用短期输入地址；最小化元数据；完成用户授权和人工审核；记录模型快照与项目数据控制证据。

### 3.3 暂不批准

- 个人 ChatGPT 账号上传真实订单照片；
- 未完成专项评估的未成年人照片；
- 身份证明、联系方式和无关个人资料；
- 未经授权的真人声音或公众人物；
- 通过未经审查的第三方连接器继续传递用户素材。

## 4. xAI API/Enterprise 初步评估

| 项目 | 官方公开信息摘要 | Hildors 初步结论 |
|---|---|---|
| API 训练使用 | xAI API 安全 FAQ 表示，未经明确许可不使用 API 输入输出训练 | 可接受，但生产团队不得主动选择共享 |
| API 默认保留 | 默认加密保存请求与响应 30 天用于滥用审计 | 不能宣传为默认零保留 |
| ZDR | 官方文档提供 ZDR，并可通过响应头确认是否启用；部分有状态功能不兼容 | 生产系统应对每次调用记录 ZDR 响应头 |
| 企业内容 | 企业条款/FAQ区分业务数据与消费者内容 | 必须使用对应企业/API方案，不能套用消费者入口 |
| 输入输出权利 | 企业条款说明客户保留输入权利，并在适用条件下拥有输出 | 可进入商用评审，但客户仍承担输入及输出使用风险 |
| 集成能力 | 企业条款允许在约定范围内通过 API 构建并向终端用户提供集成服务 | 仍需核对实际订单和产品功能范围 |
| 数据处理 | DPA 提供企业数据处理和删除框架 | 正式人物业务前应取得并审查适用 DPA/合同 |

主要依据：[xAI API 安全 FAQ](https://docs.x.ai/developers/faq/security)、[xAI 企业 FAQ](https://x.ai/legal/faq-enterprise)、[xAI 企业服务条款](https://x.ai/legal/terms-of-service-enterprise)、[xAI DPA](https://x.ai/legal/data-processing-addendum)

### 4.1 建议允许场景

- 去标识的需求结构化；
- 创意方向、动作脚本和内部生产说明；
- 不含原图的通用质量分析；
- 使用合成素材进行 API 流程测试。

### 4.2 附条件场景

- 宠物、商品和成年人物图像/视频能力；
- 需要 Files、Collections、Batch 或有状态 Responses 等功能的工作流；
- 开启 ZDR 后的视频输出存储与回调流程。

附加条件：使用公司 API Team/Enterprise；确认 ZDR 是否启用以及功能影响；在每次响应中记录相关数据控制状态；取得实际合同和 DPA；完成图片/视频能力的商用与内容政策审核；使用固定基准集和人工终检。

### 4.3 暂不批准

- Grok 消费者网页/App/X 入口上传真实订单照片；
- 未完成专项评估的未成年人和真人声音；
- 身份证明及与制作无关的个人信息；
- 员工在消费者账号中通过“关闭训练”自行获得生产批准；
- 依赖持久环境、Bot、文件或连接器但未单独审查其保存与删除行为的工作流。

## 5. OpenAI 与 xAI 对比结论

| 维度 | OpenAI API/Business | xAI API/Enterprise | Hildors 规则 |
|---|---|---|---|
| 默认训练 | 业务/API默认不训练，除非选择分享 | API默认不训练，除非明确许可 | 生产账号禁止主动共享 |
| 默认 API 保留 | 通常有最长30天滥用监控，端点应用状态另计 | 默认30天审计保留 | 用户文案按实际端点披露，不笼统写零保留 |
| 零保留 | 需资格/配置，端点兼容性不同 | 提供ZDR，部分功能受限 | 每个生产项目和端点单独验证 |
| 消费者入口 | 与业务产品数据规则不同 | 与API/企业规则不同 | 均不用于真实订单素材 |
| 输出权利 | 条款赋予相关权利，但有条件和例外 | 企业条款赋予相关权利，同时保留客户责任 | 仍需输入授权、侵权审核和商用许可管理 |
| 最佳首发用途 | 去标识文本、结构化和经审查的图像工作流 | 去标识文本、创意和经审查的API工作流 | 两者先做文本辅助，不直接作为自动最终审核 |

两家都不能替代 Hildors 对肖像、商标、音乐、声音、未成年人和成品质量的责任判断。

## 6. 生产配置要求

### 6.1 OpenAI 项目

- 公司主体创建 API 组织和独立生产项目；
- 开发、测试、生产项目分离；
- 检查并保存 Data Controls 截图或导出证据；
- 不启用主动数据共享；
- 对计划使用的每个端点确认默认应用状态和 ZDR/MAM 资格；
- `store` 等参数由服务端显式配置，不能依赖默认值；
- 远程 MCP、连接器和第三方工具单独审查；
- 设置项目密钥、预算、速率和异常调用告警。

### 6.2 xAI 项目

- 使用公司 Team/Enterprise API 项目；
- 开发、测试、生产密钥分离；
- 生产人物工作流优先评估 ZDR；
- 每次调用保存可证明数据控制状态的响应元数据；
- 验证 ZDR 对 Responses、Files、Collections、Batch 和视频输出存储的影响；
- 不使用消费者聊天记录作为订单素材中转；
- 设置团队成员、预算、调用限额和停用流程。

## 7. 仍需书面确认的问题

### OpenAI

- Hildors 计划使用的具体图像/视频端点及其当前保存行为；
- 中国及目标销售地区可用的合同主体、处理地区和数据传输安排；
- 人物、未成年人和可能涉及生物识别信息的图片处理条件；
- ZDR/MAM 申请资格及图片/文件的增强控制；
- Hildors 将输出交付至硬件设备的商用和分发条款适用方式；
- 供应商、Hildors 与终端用户在投诉和侵权事件中的责任边界。

### xAI

- 当前账号是否属于 API Team/Enterprise 而非消费者产品；
- 计划使用的图像、视频和文件能力是否支持 ZDR；
- ZDR 下视频输出使用客户存储的具体实现和安全责任；
- 目标销售地区的数据处理、DPA 和传输安排；
- 人物、未成年人和声音的允许范围；
- 输出交付至硬件、公开展示和广告用途的具体合同条件。

## 9. 批准前测试

- [ ] 用合成测试数据验证请求不会进入错误项目或消费者账号；
- [ ] 验证训练分享设置处于关闭状态；
- [ ] 验证默认保留和 ZDR/MAM 配置与计划一致；
- [ ] 验证每个实际使用端点，而不是只测试文本聊天；
- [ ] 验证文件、异步任务、缓存、Batch、连接器等附加功能的数据行为；
- [ ] 验证删除、密钥撤销、成员离职和项目停用；
- [ ] 验证供应商重复回调、任务查询和成本对账；
- [ ] 完成固定质量测试集和 P20/P11 实机播放；
- [ ] 取得内部安全/隐私、商业和法律负责人的场景批准；
- [ ] 将批准矩阵配置进生产安全网关。

## 10. 复审规则

本评估至少每季度复审一次；出现以下情况立即复审：

- 官方条款、隐私政策、数据控制文档或 DPA 更新；
- 实际账号方案、合同主体或数据地区变化；
- 新增图像、视频、声音、文件、Bot、连接器或第三方工具；
- 模型静默升级或质量、成本显著变化；
- 发生安全、隐私、侵权或删除失败事件；
- 从人工网页流程迁移到 API，或从 API 改用消费者入口。
