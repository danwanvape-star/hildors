# 受控视频交付接口（本地验证阶段）

后端提供按包内单视频获取清单与文件的基础接口：

- `GET /v1/me/packages/{packageId}/clips/{clipId}/manifest`
- `GET /v1/me/packages/{packageId}/clips/{clipId}/download`

两个接口均要求用户Bearer会话；清单中的相对地址不是公开链接，也不包含令牌。每次请求重新检查会话、有效权益、已发布状态、审核及媒体检查结果。下架/撤销阻止后续请求，不能收回已经下载的文件或已开始的传输。

清单包含字节数、SHA-256、包版本及视频ID，供后续App校验下载缓存。文件支持单段Range断点读取。文件大小变化会阻止交付；App仍须完成SHA-256校验才能提交本地文件。暂不提供CDN签名链接。

默认关闭，仅测试或可信本地集成代码显式设置`app(store, { enableDownloads: true })`启用。CLI及App仍未开放下载，bootstrap能力维持关闭，不改变现有Demo体验。不存在面向用户的注册、登录或自动领取权限接口。

只交付经过审核的普通目录视频；不接入定制订单原始素材。此MP4不是厂家转码文件，`hardwareReady`始终为false。内置Demo没有后台媒体文件，不能用此接口下载。

测试使用合成字节验证交付和权限，不作为真实视频转码或手机播放验收。后续需要App安全保存会话、下载临时文件与哈希校验、取消/重试，再做真实素材端到端验收。
