# HOLOPET 与 P20 硬件适配约定

HOLOPET 首版采用“手机端养成状态 + P20 预制视频投影”。这与当前 P20 已实现的视频列表查询（`0x36`）和指定播放（`0x35`）能力一致，不依赖尚未确认的新协议。

## P20 素材文件

设备内需要预装以下透明背景/黑底全息视频：

| 互动 | 文件名 |
|---|---|
| 呼唤 | `holopet_greet.mp4` |
| 喂食 | `holopet_feed.mp4` |
| 玩耍 | `holopet_play.mp4` |
| 休息 | `holopet_sleep.mp4` |

App 会先查询设备视频清单。文件存在时调用指定播放；文件缺失或设备离线时，仅更新手机端养成状态并明确提示，不模拟投影成功。

## 当前边界

- 不宣称实时 3D、空间定位、摄像头识别或触摸感应。
- 宠物数值由手机端管理，P20 只负责播放对应动作视频。
- 当前版本不含账号云同步与跨设备状态同步。
- 后续若固件增加主动事件、能力位图和素材包安装/校验协议，再扩展自动待机动作、设备端连续状态和一键素材安装。
