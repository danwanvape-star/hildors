# Hildors P20 App 第一版产品规格

## 1. 产品目标

第一版面向在设备附近使用 P20 的个人及现场用户，通过 Wi-Fi 局域网完成设备连接、内容管理、投影控制和蓝牙音响状态管理。

首版不依赖云端控制。即使互联网不可用，只要手机与 P20 处于同一局域网，核心控制和本地内容传输仍应可用。

## 2. 系统角色

- **控制手机**：运行 Hildors App，通过局域网 TCP 控制 P20。
- **P20**：管理设备内视频、投影硬件和蓝牙音频模块。
- **蓝牙音源**：手机、电脑或播放器，通过经典蓝牙向 P20 输入音频。
- 控制手机与蓝牙音源可以是同一台设备，也可以是不同设备。

## 3. 连接状态模型

App 必须分别展示控制连接和音频连接，不得合并为一个“已连接”。

### 3.1 局域网控制状态

| 状态 | 用户文案 | App 行为 |
|---|---|---|
| 未配置 | 尚未添加设备 | 展示添加设备入口 |
| 搜索中 | 正在查找 P20 | 展示扫描进度和手动输入 IP |
| 连接中 | 正在连接设备 | 禁用控制按钮，允许取消 |
| 已连接 | 局域网控制已连接 | 读取设备完整状态 |
| 重连中 | 连接中断，正在重连 | 按 1、2、4、8、15、30 秒退避重试，保留上次状态但标记为过期 |
| 已断开 | 设备连接已断开 | 提供重试、检查 Wi-Fi 和热点引导 |
| 不可达 | 找不到设备 | 提供诊断步骤 |

### 3.2 蓝牙音频状态

| 状态 | 用户文案 | 画面策略 |
|---|---|---|
| 不可用 | 蓝牙模块不可用 | 显示硬件或协议异常 |
| 等待连接 | 等待蓝牙音源连接 | 播放蓝牙待机画面 |
| 连接中 | 蓝牙正在连接 | 播放连接动画 |
| 已连接 | 已连接音源 | 显示音源名称和音量 |
| 播放中 | 蓝牙音频播放中 | 播放蓝牙状态视频 |
| 已暂停 | 蓝牙音频已暂停 | 保持或暂停状态视频，规则待确认 |
| 已断开 | 蓝牙连接已断开 | 按恢复策略处理 |

## 4. 工作模式状态机

### 4.1 本机播放模式

- P20 开机后进入本机播放模式。
- 按设备设置自动播放指定视频或播放列表。
- 视频和声音均来自 P20 内部文件。
- App 可控制播放、暂停、上一条、下一条、播放模式、亮度和角度。

### 4.2 蓝牙音响模式

- 外接音源通过蓝牙连接 P20。
- P20 接收并输出外接设备的音频。
- P20 同时播放蓝牙状态对应的视频。
- App 通过局域网显示蓝牙状态，并控制音量、静音和蓝牙状态视频。

### 4.3 模式切换原则

1. 开机默认进入本机播放模式。
2. 蓝牙音源连接后，P20 根据设备策略进入蓝牙音响模式。
3. 切换时停止或静音本机视频音频，禁止两个音源同时输出。
4. 蓝牙断开后，根据用户设置执行：
   - 恢复上次本机视频；
   - 从本机播放列表第一条开始；
   - 停留在蓝牙等待画面。
5. 所有切换必须由 P20 返回最终模式，App 不得仅凭按钮点击推断成功。

## 5. 首版信息架构

### 5.1 首页

- 局域网控制连接状态。
- 当前工作模式。
- 当前本机视频或蓝牙状态视频。
- 蓝牙音源连接状态和名称。
- 播放/暂停、上一条、下一条。
- 音量、静音、亮度快捷控制。
- 进入设备管理和内容上传。
- 错误、重连及上传进度提示。
- 设备电量、充电状态和低电量提醒。

### 5.2 内容

- 设备内视频。
- 手机本地视频。
- 蓝牙状态视频。
- 搜索、收藏和最近播放（首版保存在本机）。
- 上传、删除、重命名、排序和指定播放。
- 上传任务的准备、传输、校验、成功、失败和重试状态。

### 5.3 场景（协议能力确认后启用）

- 保存视频、亮度、角度、音量和播放模式组合。
- 一键应用场景。
- 首版不支持云同步。

### 5.4 我的

- 已添加设备。
- 收藏和最近使用。
- 使用教程。
- 联系我们。
- App 版本和隐私设置。
- 定制服务作为独立业务入口，不阻塞设备控制主流程。

## 6. 核心用户旅程

### 6.1 首次连接

1. 用户打开 App。
2. App 说明需要的局域网权限。
3. 用户连接 P20 热点或将 P20 配置到路由器。
4. App 连接 `192.168.4.1:8900` 或用户选择的局域网设备。
5. App 查询运行状态、视频列表、版本和蓝牙状态。
6. 首页显示“局域网控制已连接”。

### 6.2 本机内容投影

1. 用户进入内容页。
2. 选择设备内视频或手机本地文件。
3. 本地文件先校验格式、大小和设备空间。
4. App 上传视频并显示逐包进度。
5. 用户预览并设置亮度、角度和播放模式。
6. App 发送指定播放指令。
7. P20 应答成功后，首页进入“本机播放中”。

### 6.3 蓝牙音响

1. 用户在首页进入蓝牙音响卡片。
2. App 指引用户在音源设备系统蓝牙设置中选择 P20。
3. P20 上报蓝牙已连接及音源名称。
4. P20 切换到蓝牙音响模式。
5. P20 播放蓝牙状态视频并输出外接音频。
6. App 显示音量、静音、音源名称和断开状态。
7. 蓝牙断开后，P20 执行用户选择的恢复策略。

## 7. 异常与恢复

| 异常 | 判断依据 | 用户处理 |
|---|---|---|
| 手机不在 P20 局域网 | TCP 地址不可达 | 打开 Wi-Fi 设置或重新配网 |
| TCP 超时 | 指令超过约定时间无应答 | 自动重试一次，随后提示重新连接 |
| P20 重启 | 连接关闭且设备短暂不可达 | 自动重连并重新读取完整状态 |
| 视频上传中断 | 包序号或连接异常 | 保留任务，重新连接后按协议决定续传或重传 |
| 设备空间不足 | 上传应答错误码 | 引导删除内容并重试 |
| 蓝牙音源断开 | P20 主动状态上报 | 显示断开原因并执行恢复策略 |
| App 进入后台 | 系统暂停网络或进程 | 回到前台后重新查询状态，不沿用旧状态 |
| 设备低电量 | 电量小于等于 20% | 首页提示，避免执行大文件上传 |
| 设备严重低电量 | 电量小于等于 10% | 强提醒并建议立即充电 |

## 8. 产品验收原则

- 用户能明确区分“局域网控制连接”和“蓝牙音源连接”。
- 所有控制操作必须基于 P20 应答更新 UI。
- App 不把“指令已发送”等同于“设备执行成功”。
- 网络恢复后必须重新读取完整状态。
- 无互联网时，局域网控制和手机本地上传仍可工作。
- 未获得新版蓝牙协议前，蓝牙入口可以展示为“能力待接入”，不得模拟成功状态。
- 危险操作（删除全部、恢复出厂、网络切换）必须二次确认。
