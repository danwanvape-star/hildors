# App目录联调

当前增量：移动端数据接口和只读目录页面已接入，可读取后台角色包及包内单视频。默认未配置地址时维持现有Demo页面。配置后不把网络错误伪装成Demo数据。

## 运行

```powershell
node backend/src/server.mjs
E:/Flutter/flutter/bin/flutter.bat run --dart-define=HILDORS_API_BASE_URL=http://127.0.0.1:8787
```

以上URL适用于同机桌面调试。Android USB联调可以先执行`adb reverse tcp:8787 tcp:8787`，再使用相同地址。后台默认只监听本机，不自动改成公网或局域网监听。手机直接访问127.0.0.1是手机自身，未设置端口转发会连接失败。

Android/iOS的HTTP开发访问须满足平台网络策略；正式服务使用HTTPS。此轮尚未验证iOS签名构建或真机网络策略。Web构建可编译，但目录网络传输当前返回不支持，展示可重试错误；不是Web联调实现。

## 行为

- 按后台游标分页，组合目录；重复ID、循环游标、非发布内容、无效视频结构明确失败。
- 请求超时15秒，单页最大2MB，不携带管理员令牌，不自动跟随重定向。
- 查看来源、标签、包内单视频及真实时长；支持搜索和出处筛选。
- 暂无公开图片交付接口，远程页面显示中性视频图标，不使用未经授权的私有缩略图URL。
- 下载、领取、收藏同步和发送设备未接入此远程页面；不构造虚假的视频文件路径。
- 旧内容库、我的角色、本地待处理播放列表行为保持默认配置。

## 验证

`test/remote_catalog_test.dart`覆盖分页、重复/无效响应、重试、视频详情和窄屏大字号。后端真实素材处理验收独立见backend_media_acceptance.md。

本轮验证：新增目录模块静态分析无问题；远程目录、现有目录和藏品导航共10项测试通过。网络响应使用测试注入，尚未完成App与真实后台的真机端到端联调。本轮未更新APK或部署公网服务。
