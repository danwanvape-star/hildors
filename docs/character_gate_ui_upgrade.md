# 角色之门 UI 升级

## 范围

模块使用独立的 `GateScaffold` 和 `GateDesign`，覆盖入口、原创角色库、定制申请、创作者认证与收款资料、任务大厅、平台报价、订单制作与验收、收益明细和平台运营子页面。未更改仓储接口、订单状态值、收费规则或设备传输实现。

深蓝背景、薄荷色主操作、低对比边框和统一圆角构成模块视觉语言。入口复用项目已有角色图片；没有引入远程素材或新依赖。收藏与创作者入口在宽屏并列，手机纵向排列。详情和表单最大宽度为 880，角色库和运营页最大宽度为 1180。角色库使用自适应列数；表单地区选项支持长文本。

订单状态同时使用文字、图标和色彩，制作过程以四阶段展示。任务大厅的状态筛选只过滤已有授权任务，不改变仓储筛选条件。运营页可以按预审、报价、争议、结算和隐私请求筛选，并清除筛选。

## 语言扩展

`GateCopy` 为新增流程、筛选和设备交付提示提供中文、英文、日文词典，并读取 Flutter 的当前 locale。未知语言回退中文。现有业务文案和持久化状态保留原值；这是多语言扩展基础，并非整套产品已完成翻译。后续完整本地化应将业务展示文案抽入资源文件，并在应用级配置 locale、Material 本地化和语言选择，不能直接翻译仓储状态键。

## 交付边界

未增加视频下载、媒体导出、复制媒体地址或绕过绑定设备的入口。受控预览、验收和设备交付继续调用现有接口。原型中的支付服务、云端权益和真实设备传输未接入提示予以保留；本次 UI 升级不代表这些服务已经可用于生产。

## 验证

保留现有测试，另增 `character_gate_responsive_test.dart`：覆盖 320 / 768 / 1440 宽度、1.3 倍字号、主要页面滚动、任务筛选不修改仓储数据和新增语言词典。

可选截图测试通过 `GATE_CAPTURE=true` 开启；`GATE_CAPTURE_FONT` 可传入本机字体路径，用于视觉检查，不会将系统字体打包到应用。输出位于 `build/gate-ui/entrance.png`。

Flutter 分析入口在本机出现 LSP JSON 截断异常时，可以用同一 SDK 的 `dart analyze` 运行静态检查。无关模块既有的诊断不在本次修改范围内。

## 第二轮：读取状态与恢复体验

角色库、我的角色、创作者入口、任务大厅和平台运营队列统一使用加载与错误提示。读取尚未完成时不展示空列表；读取失败时提供重新加载，不展示底层路径或异常内容。角色库、收藏、任务大厅和运营队列增加刷新入口，读取期间禁用重复刷新。

请求返回前离开页面不会触发已销毁页面更新；早发晚到的请求不会覆盖更新的结果。数据只在完整读取成功后应用，读取失败不会执行仓储写操作。任务筛选无结果时提供明确说明和清除筛选按钮，清除筛选不重新读取仓储。

新增的加载、错误、刷新和筛选恢复文案提供中英日文扩展。模块主题缓存为不可变实例，避免在每个标题或状态组件重建时重复创建主题。

新增 13 项测试，覆盖五个页面的读取失败与恢复、刷新失败后的状态、离开页面后的异步返回、筛选清除、过期响应防护，以及 320 宽度、两倍字号的日文错误页面。保留原有业务测试和仓储接口。

## 第三轮：关键操作与弹窗

设备发送在本页面内串行执行，并读取设备权益状态后再显示成功；未确认目标角色已加入设备状态时不会显示发送成功。沿用现有受控接口和原型提示，没有新增视频下载、媒体导出或绕过设备绑定的能力。

## 第四轮：订单阶段与验收指引

新增只读的 `GateOrderProgress` 展示映射，收藏页和详情页共同使用。创作者匹配、评估和平台审核报价不会再显示“报价已确认”。撤回、拒绝、争议和退款订单不高亮正常制作阶段；未知状态保守展示为待确认，不推断审核或报价已经完成。已交付订单以四个完成标记呈现，不再显示为仍待验收。

为现有订单状态提供中英日文的下一步说明和报价阶段文案，并为进度条增加完成、当前、未开始的无障碍语义。关闭或暂停的订单不再显示未来付款的禁用按钮。订单详情支持主动刷新和读取失败后重试。

验收页明确提示当前原型仅展示预览记录，真实受控播放尚未接入；修改次数用尽时解释原因。已交付状态引导用户进入我的角色并通过受控流程发送到绑定设备。没有改变验收、退款或其他仓储业务状态流转，也没有增加视频下载。
