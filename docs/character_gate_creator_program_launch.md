# 角色之门：首批兼职创作者计划（90天）

## 1. 计划目标

用少量、稳定、权利清晰的兼职创作者完成第一批免费原创角色内容，并从中筛选可以承接付费专属定制的制作师。

90天目标建议：

- 邀请20–30人申请；
- 录取8–12名原创发行者；
- 发布12–20个免费原创角色；
- 每个角色完成1个可用基础包；
- 筛选3–5名付费定制制作师；
- 完成10–20个内部或补贴定制工单；
- 验证权利审核、真机质检、设备安装和奖励结算。

不以角色数量最大化为目标。没有稳定播放质量的50个角色，不如10个用户愿意长期留在设备中的角色。

## 2. 招募对象

优先招募：

- 原创角色设计师和OC画师；
- 3D角色、动画和MMD类创作者；
- 手办、潮玩和数字雕塑创作者；
- 独立游戏与虚拟角色团队；
- 擅长短循环动画、待机动作和舞蹈的制作师；
- 能理解设备限制并愿意反复做真机优化的人。

首批不优先：

- 作品集主要是未授权同人角色；
- 只会生成单张图片、没有视频一致性能力；
- 无法说明AI模型和素材来源；
- 要求直接上传游戏提取模型；
- 拒绝身份、税务、权利或工具审核；
- 只能通过私人账号和平台外渠道协作。

## 3. 招募主张

对创作者的核心价值不是“免费给平台供稿”，而是：

- 原创角色进入真实全息设备；
- 获得平台设备适配和真机质检支持；
- 获得入选赏金和活动奖励；
- 获得经过验证的安装和播放数据；
- 建立角色主页和创作者认证；
- 优秀者进入付费专属定制派单池；
- 保留原创IP，不因投稿自动转让所有权。

招募文案：

> 让你的原创角色真正来到用户桌面。角色免费向Hildors设备用户开放，入选创作者可获得制作奖励、设备适配支持，并有机会进入专属定制接单计划。

避免使用“获得海量曝光”“未来一定商业化”等无法保证的承诺。

## 4. 两阶段录取

### A. 原创发行者测试

申请材料：

- 3–5件代表作品；
- 一个拟上架原创角色；
- 原创过程或源文件证据；
- 使用的AI和制作工具；
- 第三方素材、字体、音乐和模型来源；
- 每周可投入时间；
- 是否具有动画和设备适配能力。

测试任务：制作一个5–10秒无音乐待机循环，使用平台提供的技术模板。

通过标准：

- 权利链清楚；
- 角色有记忆点；
- 多帧形象稳定；
- 动作适合循环；
- 黑底和轮廓适合设备；
- 能按反馈修复；
- 文件和制作记录完整。

### B. 付费接单资格测试

只有原创发行测试表现稳定的人或经过单独审核的专业制作师可以申请。

测试内容：

- 根据给定角色基准制作指定动作；
- 保持锁定细节；
- 修复一组预设缺陷；
- 完成设备规格输出；
- 在规定时间内提交版本和说明；
- 正确处理一次模拟需求变更。

通过后先获得`Verified`等级，每周最多并行1–2个真实订单。

## 5. 首批角色内容规格

每个免费角色基础包必须包含：

- 1张商城封面；
- 1个5–10秒初次见面；
- 3个5–15秒待机循环；
- 1个5–15秒招牌动作；
- 角色简介和性格标签；
- 角色正、侧、背基准；
- 权利与AI工具声明；
- P20适配内容包；
- 设备实测结果。

首批不强制音乐和配音，降低版权与制作成本。音乐内容作为后续专题活动。

## 6. 角色组合策略

首批12–20个角色避免全部集中在同一审美：

| 类型 | 建议数量 | 目的 |
|---|---:|---|
| 可爱陪伴型 | 3–4 | 验证高频待机和情感连接 |
| 酷炫战斗型 | 2–3 | 验证动作、武器和男性用户偏好 |
| 偶像/舞台型 | 2–3 | 验证唱跳与音乐潜力 |
| 神话幻想型 | 2–3 | 验证视觉收藏价值 |
| 手办/潮玩型 | 2–3 | 验证实体收藏用户迁移 |
| 机械/非人型 | 1–2 | 验证特殊结构和设备辨识度 |
| 实验艺术型 | 1–2 | 发现非主流但高记忆点内容 |

每个角色必须在缩略图、设备轮廓和动作语言上能与其他角色区分。

## 7. 创作任务书

平台为每个角色建立统一Brief：

```text
角色名称
一句话身份
三项性格关键词
核心轮廓
标志性颜色
必须保持细节
禁止变化细节
待机行为逻辑
招牌动作
设备型号与安全区
黑底和轮廓要求
文件规格
权利与AI声明
里程碑和截止日期
奖励和结算条件
```

平台反馈必须指向任务书或设备问题，不使用“感觉不够高级”等无法执行的评价。

## 8. 奖励模型

### 固定奖励

建议内部测试预算：

- 通过测试任务：US$20–50；
- 基础角色包审核和真机通过：US$100–250；
- 平台额外委托一个动作：US$30–100；
- 特殊复杂结构或高质量角色：单独报价。

这些是预算假设，需要根据真实人工时间调整。

### 使用奖励

每个角色设置90天封顶奖励，避免不可控长期成本。

示例：

- 达到100台不同设备成功安装：奖励A；
- 达到500台：奖励B；
- 达到1000台：奖励C；
- 30日仍有有效播放设备：额外质量奖励。

具体金额在活动开始前写入任务书。

### 非现金支持

- 借用或折扣购买测试设备；
- 官方创作者认证；
- 角色主页推荐；
- 平台制作工具额度；
- 设备适配培训；
- 付费定制派单资格。

非现金权益不能替代已经承诺的现金奖励。

## 9. 有效使用与反作弊

奖励不按浏览量或简单领取量计算。有效安装要求：

- 真实账户；
- 真实受支持设备；
- 设备返回安装成功；
- 同账户、同设备、同角色在周期内只计一次；
- 排除内部测试和创作者自有测试设备；
- 排除模拟器、异常批量账户和短期重复重装。

有效播放建议要求：

- 安装后至少在不同日期播放；
- 达到最低累计时长或完整播放次数；
- 数据只记录内容ID、设备ID派生标识、时间和完成状态，不记录用户环境音频。

对刷量判断提供人工复核和创作者申诉入口。

## 10. 内容评审

采用100分内部评分，但不向用户展示总分：

| 维度 | 权重 |
|---|---:|
| 原创与权利完整性 | 一票否决 |
| 角色记忆点 | 20 |
| 设备显示效果 | 25 |
| 动作和循环质量 | 20 |
| 多帧角色一致性 | 15 |
| 技术交付完整度 | 10 |
| 修改响应和协作 | 10 |

建议75分以上且无否决项才发布。评分用于统一内部判断，不替代具体修改意见。

## 11. 从免费上架到付费接单

晋级条件建议：

- 至少一个原创角色完成发布；
- 连续两个内容包真机一次或两次内通过；
- 无权利和素材安全违规；
- 修改响应准时；
- 完成接单测试；
- 接受平台里程碑、保密和用户素材规则；
- 每周有稳定产能。

进入派单池后，免费内容表现只是参考，不按角色人气直接垄断订单。

## 12. 付费定制派单

P0只派发：

- 完整素材的OC Lite；
- 原创手办数字陈列；
- 已建立角色基准的模板动作；
- 平台原创角色的个性动作。

暂不派发：

- 未授权游戏或动漫角色；
- 真人和声音克隆；
- 多角色复杂互动；
- 商业广告和高风险品牌项目；
- 需要源文件交付的项目。

每个制作师首月最多并行1个订单，稳定后增加至2–3个。

## 13. 创作者工作台

首发只需要五个模块：

1. **资格与资料**：身份、税务、收款、协议和技能；
2. **我的原创角色**：草稿、审核、发布和使用数据；
3. **可接任务**：去标识化摘要、报酬、工期和范围；
4. **进行中任务**：里程碑、素材、反馈和版本；
5. **收入与记录**：奖励、订单分成、扣除和付款状态。

不在P0制作社区聊天、粉丝私信、自由竞价和复杂社交功能。

## 14. 每周运营节奏

### 周一

- 检查创作者产能；
- 分配测试和定制任务；
- 汇总超时与风险项目。

### 周三

- 内容中期审核；
- 集中处理素材和设备问题；
- 避免截止日前一次性发现大量问题。

### 周五

- 真机质检；
- 发布排期；
- 结算审核；
- 复盘返工和用户反馈。

### 每月

- 发布原创角色榜单；
- 更新创作者等级；
- 结算固定和使用奖励；
- 复核权利、质量和安全事件；
- 调整下一月角色组合和预算。

## 15. 90天计划

### 第1–30天：建立供给

- 完成招募页、申请表和协议；
- 邀请20–30人；
- 进行待机循环测试；
- 录取第一批8–12人；
- 确定首批角色组合；
- 发布3–5个内部角色。

### 第31–60天：形成免费角色库

- 发布第一批8–12个创作者角色；
- 完成免费领取和设备安装；
- 记录安装、播放和真机问题；
- 启动第一个主题创作活动；
- 对候选制作师进行接单测试。

### 第61–90天：验证定制收入

- 原创角色总量达到12–20个；
- 3–5名制作师进入派单池；
- 完成10–20个内部或补贴定制工单；
- 小规模开放付费OC Lite、手办数字陈列和模板动作；
- 计算每单人工时间、返工、毛利和用户留存；
- 决定下一阶段招募和定制名额。

## 16. 预算框架

90天创作者预算分为：

```text
测试任务奖励
+ 角色基础包赏金
+ 额外动作委托
+ 有效安装/播放奖金
+ 测试设备和物流
+ 平台AI工具额度
+ 权利审核和真机质检人工
+ 税费、付款和风险准备
```

预算控制不应通过拖欠创作者报酬实现。可以减少录取人数、角色数量和动作数量，但已确认任务必须按约结算。

## 17. 成功判断

90天后继续扩大计划，需要同时满足：

- 至少30%的激活设备领取一个原创角色；
- 免费领取后的设备安装成功率达到内部目标；
- 有一批角色在30天后仍被真实播放；
- 真机质量和权利审核没有失控；
- 创作者每小时有效收入具有吸引力；
- 至少部分免费角色用户转向专属定制；
- 付费定制单笔毛利为正；
- 用户能清楚理解免费内容与付费定制的区别。

具体百分比应根据首轮样本量和设备基线校准，不能为达成指标人为降低有效播放标准。

## 18. 最终模式

```text
创作者贡献免费原创角色
→ 用户免费领取并安装
→ 角色获得真实使用数据
→ 优秀创作者进入付费接单池
→ 用户为自己的OC、手办和专属动作付费
→ 创作者获得稳定订单收入
→ 免费角色供给继续扩大
```

这比直接向陌生原创角色收费更容易建立信任，也比要求兼职创作者长期无偿供稿更可持续。

创作者申请、测试任务、原创角色提交、审核修改、定制项目、奖励和结算的页面级体验见 [character_gate_creator_portal_ux.md](./character_gate_creator_portal_ux.md)。
