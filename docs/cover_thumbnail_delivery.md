# 角色封面缩略图与重试

2026-09-18 修复 Nova 列表封面长期加载失败。

## 原因与调整

原目录直接使用 1254×1254 PNG 原图，大小 1,257,889 字节。本机访问返回 200，但 25 秒只收到部分内容。Nginx 配置未发现显式限速指令；此测量不能代表所有手机网络。

保留 `coverPath` 原图，增加 `coverThumbnailPath`，公开缩略图接口只允许当前已发布的封面。按需生成最长边 384 像素的 JPEG，缓存复用、原子写入，并限制输入大小、像素量、处理时间及并发数量。响应前再次检查发布状态。

App 列表、创作者作品列表和下载后的封面缓存优先使用缩略图；详情主图保留原图。旧服务器未提供缩略图字段时兼容原图。图片失败后可点击刷新图标重试，仅清除当前图片的内存缓存，不清空用户本地内容。
