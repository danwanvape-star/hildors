# 角色包与设备播放列表

- 藏品分为“内容库”和“我的角色”；内容库包含官方内容、原创角色。
- 一个角色对应一个视频包，一个包可包含多条独立视频。列表引用包 ID + 视频 ID，不把角色 ID 作为设备文件名。
- 保留已有四个可播放 Demo，各作为单视频示例包；不为仅有概念图的角色虚构视频。
- 播放列表的“添加视频”提供“从我的角色选择”、手机文件导入、设备已有视频三种来源。
- “我的角色”选择页与藏品的归属一致：只展示已收藏的角色及已交付的定制角色，不自动混入公共 Demo。进入角色后勾选独立视频；暂无角色时可浏览内容库，返回后刷新收藏。
- 藏品“我的角色”和播放列表选择入口共用缩略图网格：常规手机三列，窄屏或大字号两列；不再显示重复的“我的收藏”标题。
- 从“我的角色”直接选视频后，可指定加入“日常展示”或“音乐联动”待处理区，保留目标列表已有记录。由播放列表进入时直接返回所选视频，沿用进入时的目标列表。
- 手机文件不再复制到独立 App 内容库；文件选择器可能使用系统缓存，取景参数仍可保存在本机。
- 新选视频进入当前列表的待处理区，按开机/蓝牙分别持久化引用。退出重进可恢复；不复制媒体，既有本地素材不删除。
- 源文件移动、删除或系统缓存清理后，进入取景时提示重新选择。移除待处理记录须确认，不删除源文件或设备文件。
- 待处理不代表已上传。待厂家转码接口接入后，完成转码、上传确认再建立真实设备文件关联。
- 播放前查询硬件文件列表，文件不存在则不发播放命令。
- 原创及定制角色暂缺真实视频清单，显示“尚未提供可用视频文件”。定制服务继续禁止原始文件下载、导出；后续只走受控设备交付。
- 两套播放列表写入及转码仍有厂家依赖，本次不宣称已完成硬件闭环。
