# HILDORS 腾讯云北美首发部署与费用测算

核对日期：2026-09-14。状态：选型与测算，未购买、部署或修改域名。目标用户以北美为主。以下规格是起步压测候选，不是并发容量承诺；金额使用美元，不含税、汇率、折扣和促销。

## 一、部署决策

先用美国单一主区域，不做多云或东西海岸双活。弗吉尼亚为首个测试候选，硅谷为对照；根据东/西海岸与加拿大测试用户的接口延迟、下载成功率、上传速度，以及所需产品库存和最终报价决定。腾讯云CVM官方列出硅谷与弗吉尼亚各两个可用区；不同产品的版本/高可用规格不一定覆盖相同可用区，购买前逐项确认。

API、数据库、视频处理任务和COS放同一地域；正式上线尽量跨可用区部署API与数据库高可用节点。数据库不开放公网。安卓/iOS共用业务接口，国内运营团队通过受保护的Web后台工作；局域网硬件控制不经过云端。

## 二、资源清单

| 资源 | 内测候选 | 正式收费上线候选 | 购买前确认 |
|---|---|---|---|
| API CVM | 1台，2核4GB，Linux | 2台2核4GB起，同区域不同可用区，压测后调整 | 实例型号、磁盘、公网、可用区库存 |
| 数据库 | 托管PostgreSQL，2核4GB/50GB级别候选 | 支持故障切换的高可用规格，备份与恢复演练 | 对应规格是否销售、备份保留、跨区能力与价格 |

50GB数据库、2核4GB等均非已确认腾讯云可售SKU。不应照表盲买；内测单机有停机风险，不作为收费服务的高可用方案。

首期不需要Kubernetes、大型Redis集群、跨洲实时数据库复制或GPU集群。队列机制需要，但可先用可靠的数据库任务表，按实际吞吐升级。

## 三、可核实的下载流量测算

假设每位月下载用户下载20条视频、平均50MB，暂不计封面、重试和重复下载。这里用户数是发生下载的用户数，不是注册数。

估算公式：下载GB = 用户数 × 每用户下载次数 × 平均MB ÷ 1000。

腾讯云国际站CDN北美流量公开阶梯单价：0–2TB为0.0452美元/GB；2–10TB为0.0378；10–50TB为0.0319。按月阶梯累进，非全部流量套最低档。账户实际产品和结算站点需确认，不能直接套用国内站人民币套餐。

| 月下载用户 | 下载量（十进制近似） | 仅CDN下行费参考 |
|---|---:|---:|
| 100人 | 100GB | 约4.52美元/月 |
| 1,000人 | 1,000GB | 约45.20美元/月 |
| 10,000人 | 10,000GB | 约393美元/月 |

大档仅给近似数：采用2TB=2048个计费GB边界时，10,000GB为2048×0.0452＋7952×0.0378≈393.16美元；实际字节换算以账单计量规则为准。平均文件变为100MB时流量翻倍，费用需重新按阶梯计算，不应简单翻倍原总价。

以上绝不是完整月费用，也没有测量实际用户下载行为。COS使用CDN时仍有存储、请求与回源费用。若App直接走COS源站，则对应外网下行费用，不要把同一条交付路径的CDN下行和COS直出同时重复计入。

## 四、完整费用公式与待报价项

月总额 = API实例/磁盘 + 数据库/备份 + 负载均衡 + 任务机工时 + COS存储/请求/回源或直出 + CDN下行 + 日志/安全/网络附加项 + 邮件登录等第三方费用。

| 需要填入报价的项目 | 数量/用量依据 |
|---|---|
| API计算与磁盘 | 内测1台、正式2台；按实际月小时或包月价格 |
| PostgreSQL | 实例规格、数据盘、超额备份分别核价 |
| COS存储 | 正式片＋手机预览＋硬件版＋定制原始素材＋版本保留，不只算目录视频 |
| 回源流量 | 下载量×实际回源比例，初期冷缓存可能较高 |
| 任务处理 | 单视频实测CPU时长×处理次数，重试另计 |
| 附加网络与安全 | 公网/NAT（若使用）、负载均衡、日志、WAF、跨区域备份 |
| 非云资源成本 | 角色授权、制作人工、AI生成、支付手续费、客服另列，不混入服务器费用 |

当前未取得登录账号下的正式CVM和数据库报价，因此不提供虚假的月总价。取得上述单价后再合计，并预留20%–30%容量/异常流量预算；这只是规划余量，预算告警不是自动费用硬上限。

可先按1,000名月下载用户做内测模型，但这只是用于比较方案的假设，不是销量预测。3,000条×50MB的交付视频约150GB，另有预览、转码版本和定制素材。10,000名下载用户的示例CDN费用约393美元，其余组件仍须叠加。

## 五、上线前代码与安全清单

1. 将SQLite原型迁移到生产数据库，增加迁移脚本、连接池及备份恢复测试。
2. 接正式身份服务，账号停用、会话管理、邮件登录/验证；移动端按账号隔离私有缓存。
3. 将本地媒体文件替换为COS适配层；业务API不转发大视频，签发短时受控下载凭证。
4. CDN URL鉴权与COS源站权限分别配置；现有App强制同源下载，改为经校验的指定交付域名，不能把账号Bearer发送给CDN。
5. 定制素材私有，制作人员仅访问分配订单；来源素材不进入公共CDN缓存。
6. 生产环境独立配置、密钥管理、HTTPS、限流与审计；测试fixture与临时授予权益逻辑不得成为用户入口。
7. 任务隔离、失败重试和资源上限；通用FFmpeg检查不等同厂家硬件转码。
8. 至少测试北美东/西海岸及加拿大的登录、列表、50MB下载与定制上传；记录P50/P95与成功率，再定最终区域。
9. 执行数据库恢复、账号过期、内容下架、断网、取消、哈希损坏和存储不足测试。

当前本机端到端通过不代表已满足这些生产条件；不直接把原型8787端口开放到公网。

## 六、执行顺序

先确认腾讯云账号的结算站点、可售区域与首期预算 → 导出CVM/数据库/COS/CDN完整报价 → 用户批准购买 → 建隔离测试环境 → 压测与安全验收 → 灰度启用。没有购买授权前仅完成配置模板与迁移代码，不创建付费资源。
