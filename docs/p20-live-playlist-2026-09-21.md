# P20 设备实际播放列表（0.1.53 / 54）

## 行为

- 播放列表以当前连接设备的 0x36 查询结果为准。进入已连接页面或重新连接后自动读取，支持 A/B 切换和手动刷新。
- 未连接、断开连接时清空设备列表；过期异步查询不得把旧设备内容重新显示出来。不再使用示例视频或手机本地草案充当设备文件。
- 点击播放发送 0x35；上移、下移发送 0x38。排序前核对设备当前列表，避免按过期索引移动错误文件；操作完成重新读取确认，不乐观宣称已保存。
- 支持单曲循环、顺序循环、随机循环、单次播放。0x08/0x09 不携带列表编号，因此播放方式按设备全局设置展示，A/B 共用。
- 手机待上传记录独立展示；保留源视频选择、画面调整、A/B 音频规则和上传进度诊断。上传成功重新读取设备列表。
- 不显示协议未提供的虚构时长、播放次数。设备文件画面调整需要选择原视频并上传新文件，保留原设备文件。
