## 建议体验顺序

0.1.22 重点复测：原创角色馆改用小图列表，显示创作者和上架日期。当前示例无真实作者及日期，显示未提供；页面已支持昵称、匿名和日期元数据。点击整行进入详情领取，返回后刷新状态。

0.1.21 重点复测：照片使用系统文件选择器，长按尝试多选；也可连续添加多批，最多八张，取消保留此前选择。来源入口改为“这是我想要的角色”“这是我的手办”。发现页采用专属定制大卡片与三个紧凑入口，普通字号尽量一屏展示，大字号可滚动。手机原生多选兼容性尚待用户复测。

1. 免费原创角色：浏览封面和分类，进入详情，领取，返回检查收藏状态。
2. 我的角色：检查已领取角色、定制进度及设备操作反馈。
3. 定制你的专属角色：选择来源，填写免费预审申请，选择素材，检查必填提示、键盘和提交结果。
4. 创作者工作台：检查入驻资料、审核状态、任务大厅和收益页面；有相应订单数据时继续体验报价、制作与验收。
5. 在系统中放大字体，检查页面滚动、按钮和返回操作。可通过系统语言测试已接入的中英日文案；部分创作者、运营与收藏页面仍使用中文。

## 当前范围

这是 UI 与本地业务流程体验包，不代表真实支付、云端权益、真实受控媒体交付已接入。没有视频下载或导出入口。设备操作以当前页面实际提示为准，本地记录不代表真实设备回执。

运营页面保留于代码与自动化测试中，当前未开放普通用户导航入口。没有订单或审核数据时，部分后续状态页面不会自然出现。

安装包包含当前共享工作区的 App 代码，本任务仅改动角色之门相关页面。反馈问题时说明所在页面、操作步骤和实际表现即可；涉及布局问题可附截图。

