# Hildors AI 工具首轮盘点工作表

## 1. 默认管理结论

在账号方案、当前条款、数据处理和商用许可完成书面核实前，所有工具统一按以下规则管理：

- 真实人物、未成年人、真人声音、身份证明：**禁止上传**；
- 宠物和商品真实素材：**仅限内部授权测试，不进入付费交付**；
- 去标识的结构化需求、动作描述、错误分析：**可在人工复核下测试**；
- 合成测试图和无真实主体的样例：**可用于能力评估**；
- 生成工具投入内部使用前的每项结论必须填写证据、日期和负责人，不能凭个人经验标记“可商用”。

这不是对任何工具能力或政策的最终判断，而是资料未核实阶段的默认安全状态。

## 2. 工具条目拆分规则

每个实际接入方式单独建条目：

- GPT 网页个人版；
- GPT 团队/企业工作区；
- OpenAI API 项目；
- Grok 网页或 App；
- xAI API 项目；
- 每个图像生成工具的网页端和 API；
- 每个视频生成工具的网页端和 API；
- 本地安装或自托管模型；
- 剪辑、抠像、补帧、配音及转码工具；
- 员工目前用于试验但未正式采购的工具。

不同条目不得共享审批结果、账号、密钥或费用上限。

## 6. 固定测试集

### 6.1 测试素材构成

使用合成素材或有明确内部测试授权的素材：

- 宠物 10 组：不同毛色、长短毛、耳形、体型和复杂花纹；
- 成年人物 10 组：不同年龄段、发型、眼镜、服装和全身比例；
- 商品 5 组：简单形状、反光材质、包装文字、Logo 和品牌标准色；
- 标准动作：P01–P05、A01–A05；
- 异常素材：模糊、遮挡、多主体、低分辨率和视角不足；
- 禁止测试：不得为了测试而收集无授权公众人物、未成年人或违法素材。

### 6.3 比较指标

- 第一次通过率；
- 两轮内通过率；
- 平均主体一致性得分；
- 致命缺陷率；
- 平均生成时间与 P95 时间；
- 每个合格产物的工具成本；
- 每个合格产物的人工修复分钟数；
- P20/P11 实机播放成功率；
- 相同输入重复执行的稳定性。

仅比较单次生成价格会误导选择，应以“每个合格且可在设备播放的交付物完全成本”为主指标。

## 9. 紧急停用触发器

出现以下任一事件，值班负责人可先停用再复核：

- 用户素材发送到未批准账号、工具或地区；
- 工具突然启用训练、公开分享或更长保留设置；
- 密钥、登录凭证或长期文件地址疑似泄露；
- 供应商发生与本业务数据相关的安全事件；
- 生成内容大规模出现人物认错、违规、侵权或品牌错误；
- 单位成本异常增长或循环调用；
- 工具静默更换模型导致质量显著下降；
- 删除请求不能执行或供应商无法确认删除范围；
- 账号被封禁、额度异常或在途任务无法查询。

停用后：停止新任务、盘点在途订单、保存审计证据、切换人工或备用流程，并评估是否需要通知用户。

## 11. 首轮完成定义

只有同时满足以下条件，才算完成工具盘点：

- 所有实际使用工具和账号均已登记；
- GPT、Grok、主要图像和视频工具分别形成独立结论；
- 每个工具有条款、隐私、商用、安全和价格证据；
- 每个数据类型和订单风险等级都有允许或禁止结论；
- 人物、未成年人、声音和商用订单不存在模糊的“应该可以”；
- 固定测试集已完成质量、成本和设备播放测试；
- 生产系统已按白名单阻断未批准调用；
- 每项核心能力已有备用工具或人工方案；
- 账号、密钥、预算、审计和离职回收机制已落实；
- 已完成至少一次供应商紧急停用演练。
