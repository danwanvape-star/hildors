# Hildors 照片视频定制：中国市场上线合规检查表

> 更新时间：2026-09-06。本文件用于产品、技术和运营准备，不构成正式法律意见。具体适用范围、备案/安全评估义务、跨境安排、协议文本和争议处理应由熟悉中国网络、数据、生成式 AI 与消费者业务的专业律师结合实际架构审定。

## 1. 重点结论

Hildors 的照片视频定制至少涉及以下合规主题：

- 可识别人物照片和肖像许可；
- 可能涉及敏感个人信息及不满十四周岁未成年人信息；
- 将照片发送给境外或第三方 AI 工具的数据处理安排；
- 使用生成式 AI/深度合成制作人物、图片和视频；
- AI 生成合成内容的显式和隐式标识；
- 定制数字内容、格式条款、退款及售后；
- 订阅自动续费、扣款提醒和便捷取消；
- 商品、商标、音乐和真人声音的第三方权利。

不能只让用户勾选一句“我同意隐私政策”覆盖所有事项。履约、敏感信息、向境外提供、案例展示、AI 改进和肖像使用范围应按适用要求拆分处理。

## 2. 主要官方依据

- 《个人信息保护法》要求同意在充分知情前提下自愿、明确作出；敏感个人信息原则上需要特定目的、充分必要性和严格保护，并取得单独同意；不满十四周岁未成年人信息需要监护人同意和专门规则；向境外提供个人信息还涉及专门告知和单独同意等要求。[中国人大网：《个人信息保护法》](https://www.npc.gov.cn/WZWSREL25wYy8vLy8vL2MyL2MzMDgzNC8yMDIxMDgvdDIwMjEwODIwXzMxMzA4OC5odG1s)
- 《民法典》规定自然人享有肖像权，未经肖像权人同意原则上不得制作、使用或公开肖像，并禁止利用信息技术手段伪造等方式侵害他人肖像权。[中国网信网：《民法典》](https://www.cac.gov.cn/2020-06/01/c_15925617772683193.htm)
- 《互联网信息服务深度合成管理规定》覆盖在境内应用深度合成技术提供互联网信息服务的相关活动，并要求建立用户注册、算法机制审核、科技伦理审查、信息审核、数据安全、个人信息保护和应急处置等制度；具体是否及如何适用于 Hildors 架构应由律师评估。[中国网信网：《互联网信息服务深度合成管理规定》](https://www.cac.gov.cn/2022-12/11/c_1672221949354811.htm)
- 《生成式人工智能服务管理暂行办法》涉及向境内公众提供生成式人工智能服务的情形，并要求提供者承担个人信息保护等责任、按深度合成规定对生成图片和视频等内容进行标识；Hildors属于直接提供者、技术支持者还是下游使用者，需要结合产品能力判断。[中国网信网：《生成式人工智能服务管理暂行办法》](https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm)
- 《人工智能生成合成内容标识办法》自2025年9月1日起施行，规定了图片、音频、视频等生成合成内容的显式与隐式标识，以及下载、复制、导出等场景要求；在符合条件并向用户提供无显式标识内容时，还涉及协议义务和不少于六个月的相关日志留存。[中国网信网：《人工智能生成合成内容标识办法》](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)
- 网络交易自动续费需要在消费者接受服务前和续费日期前显著提醒，并提供显著、简便的随时取消或变更选项；现行消费者保护规则也要求经营者履行其对数量、质量、价格、售后和责任等作出的承诺。[市场监管总局：《网络交易监督管理办法》](https://www.samr.gov.cn/wljys/gzzd/art/2023/art_09c394cce74f424a8d82dbc4811a11ec.html)、[《消费者权益保护法实施条例》](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2024/art_0aea188276a44f0baf940ab95ee00e0a.html)
- 《消费者权益保护法》将消费者定作商品等列为七日无理由退货的例外类别之一，同时要求格式条款以显著方式提示与消费者有重大利害关系的内容。Hildors 的具体服务形态、数字内容交付和退款安排仍需结合合同与履约阶段审定，不能简单写成“定制品一概不退”。[市场监管总局：《消费者权益保护法》](https://www.samr.gov.cn/zfjcj/tzgg/art/2023/art_615af9ed6bcd4974bf853dd2e02bc663.html)

## 3. 主体身份和肖像授权

### 3.1 人物订单必须确认

- 上传者是否为照片本人；
- 非本人时，肖像权人是否明确同意制作；
- 授权是否覆盖 AI 处理、人工制作、视频交付和所选用途；
- 用途是个人/家庭、礼物、公开分享、门店展示还是广告；
- 使用期限、地域、媒介以及是否允许修改和再制作；
- 肖像权人是否允许声音、姓名和其他身份元素一起使用；
- 撤回授权时对未开始任务、在途任务和已交付内容的处理。

### 3.2 不接受的简单证明

- “照片在网上公开，所以可以使用”；
- “我是他的朋友/同事/粉丝”；
- “照片是我拍的，所以我有肖像授权”；
- “只是送礼物，不会侵权”；
- “AI 做的不是原照片，所以不需要本人同意”。

照片作品权利与照片中人物肖像权不是同一件事。公开照片在可能对个人权益产生重大影响的处理场景下，也不能默认无限制使用。

### 3.3 建议证据等级

| 订单 | 最低建议证据 |
|---|---|
| 本人个人使用 | 登录用户声明 + 明确肖像制作授权 |
| 为普通成年人制作礼物 | 上传者声明 + 被拍摄者可核验授权 |
| 公开展示/社交传播 | 被拍摄者对公开范围的明确授权 |
| 商业宣传/代言效果 | 独立书面肖像及商业使用许可，明确媒介、地区和期限 |
| 公众人物 | 原则上拒绝自助下单，法律与权利材料专项复核 |
| 未成年人 | 监护人身份与授权专项流程 |

## 4. 个人信息处理清单

### 4.1 数据分类

| 数据 | 用途 | 最小化规则 | 建议保护等级 |
|---|---|---|---|
| 用户账号和联系方式 | 登录、通知、售后 | 与制作素材分开 | 个人信息 |
| 人物原始照片 | 审核、角色制作 | 3–8张必要角度，不收集无关照片 | 高保护 |
| 人脸/身份特征 | 保持角色一致 | 不建立跨用户识别库 | 视具体处理可能涉及敏感个人信息 |
| 未成年人照片 | 定制制作 | 无监护人流程不处理 | 敏感个人信息 |
| 身份/授权证明 | 核实权利 | 不发送给生成模型 | 高保护 |
| 宠物照片 | 角色制作 | 删除EXIF和家庭环境无关信息 | 普通业务素材，仍可能含个人信息背景 |
| 声音样本 | 声音定制 | 单独收集、单独授权 | 视处理方式可能涉及敏感个人信息 |
| Prompt和人工备注 | 生产 | 禁止写无关姓名、电话、住址 | 可能含个人信息 |
| 生成视频 | 交付 | 与订单、许可和标识关联 | 用户内容资产 |

“人脸照片是否构成生物识别敏感个人信息”与实际是否用于身份识别、技术处理方式等有关。产品设计应按高风险保护，最终法律分类由律师结合方案判断。

### 4.2 告知事项

用户提交前至少清晰说明：

- 处理者身份和联系方式；
- 处理目的、方式和信息种类；
- 哪些信息是必需，拒绝后有什么影响；
- 保存期限或确定期限的方法；
- 用户查阅、复制、更正、删除、撤回和注销途径；
- AI、人工制作、云存储、支付等接收方类别；
- 敏感信息处理的必要性及对个人权益的影响；
- 向境外提供时适用的额外告知、接收方信息和权利渠道；
- 自动审核或风险评分对用户权益有重大影响时的说明和申诉方式。

### 4.3 同意拆分

| 同意/确认 | 是否与购买绑定 | 建议方式 |
|---|---|---|
| 为履行定制订单进行必要处理 | 必需 | 明确确认，不预勾选 |
| 肖像制作和约定用途 | 必需 | 独立授权，展示范围 |
| 敏感个人信息 | 符合条件时必需 | 单独同意 |
| 未成年人信息 | 符合条件时必需 | 监护人同意及专门规则 |
| 向境外提供 | 使用境外AI/存储且适用时 | 专门告知 + 单独同意，并完成其他适用程序 |
| 交付后保存角色工程 | 可选或订阅必需 | 明确期限和删除影响 |
| 案例展示 | 可选 | 默认关闭，可撤回未来使用 |
| 用于AI训练/改进 | 可选 | 默认关闭，不得作为购买条件 |

是否可基于“订立、履行合同所必需”处理某些数据，需要逐项进行必要性判断，不应把所有可选运营用途包装为履约必需。

## 5. 第三方与跨境 AI 工具

在把照片或声音发送给境外 AI 供应商前，至少完成：

- 明确供应商及具体产品、账号方案、端点和数据处理角色；
- 记录发送的数据种类、目的、方式、保留期、地区和子处理方；
- 确认训练使用、人工访问、删除和安全事件机制；
- 评估是否属于向境外提供个人信息及适用的法定路径；
- 向用户履行相应告知并取得适用同意；
- 进行个人信息保护影响评估并留存记录；
- 只发送任务所需数据，去除EXIF、GPS、身份证明和无关个人信息；
- 通过企业/API项目调用，不使用员工个人账号；
- 建立供应商停用、数据删除和用户权利请求协作机制。

在跨境路径未由律师和隐私负责人确认前，真实人物及声音素材不得发送至境外工具。可以优先采用境内合规服务、本地工具或去标识文本工作流降低风险，但“服务器在境内”本身也不能替代全部合规审查。

## 6. AI生成合成内容标识

### 6.1 产品必须预留的能力

- 用户预览界面明确提示“AI与人工共同制作”；
- 按适用要求在图片/视频可感知位置或播放周边提供显式标识；
- 对下载、复制和导出的文件执行标识策略；
- 在文件元数据写入生成合成属性、服务提供者标识、内容编号等必要信息；
- 保证转码、打包、下载和设备传输不会意外删除隐式标识；
- 素材库记录标识版本、生成方式和内容编号；
- 用户申请无显式标识版本时进入独立审批流程，不由客服直接提供；
- 用户服务协议说明标识方法、样式、用户发布义务和禁止恶意删除/篡改标识；
- 为应用商店上架准备是否提供生成合成服务及标识机制的说明材料。

### 6.2 Hildors 建议策略

个人设备本地播放、下载分享、公开展示和商业广告可能具有不同标识呈现方式。V1建议统一保留隐式标识和内容编号；对用户可下载/公开传播版本默认保留显式标识。设备专用版本是否可以只在播放周边或设备界面标识，须由律师结合实际服务形态确认。

不能把供应商添加的水印当作Hildors全部标识义务。供应商水印、Hildors显式标识和文件隐式标识应分别管理。

### 6.3 无显式标识版本

如果业务未来提供无显式标识版本，至少需要：

- 确认适用法规是否允许当前场景；
- 用户明确申请，而非默认提供；
- 协议明确用户的标识义务和使用责任；
- 保存对象、订单、用途和提供记录；
- 按适用要求保存不少于六个月的相关日志；
- 商用、公众人物、未成年人和高传播风险内容提高审批等级；
- 隐式标识仍按适用要求保留。

## 7. 深度合成与生成式AI治理

上线前由律师判断 Hildors 在实际链路中的身份和义务：

- Hildors是否直接向公众提供生成式人工智能或深度合成服务；
- 外部AI供应商是技术支持者、受托处理方还是独立服务提供者；
- “用户下单、人工制作、后台调用模型、交付成品”的模式是否改变适用范围；
- 是否存在算法备案、安全评估或其他主管部门手续；
- 用户实名、日志、内容审核、投诉举报和辟谣机制的具体要求；
- 应用上架、网站、公众号及设备播放分别如何满足标识和信息服务要求。

无论最终法律定性如何，V1都应先具备：内容规则、自动与人工审核、科技伦理审查记录、用户投诉、侵权下架、日志、安全事件响应和供应商治理。

## 8. 未成年人规则

- 不满十四周岁用户或主体进入独立流程；
- 取得父母或其他监护人的同意，并核实监护关系所需的最少信息；
- 制定专门的未成年人个人信息处理规则；
- 默认禁止广告代言、成人化、危险行为、敏感情节和真人声音复刻；
- 原照片不进入普通制作人员自由下载区；
- 订单至少L3，制作与最终质检双人复核；
- 案例展示和AI训练授权默认禁止，确需开展时另行专项审核；
- 提供监护人查阅、更正、删除和撤回渠道；
- 保存期限从严，任务完成后及时删除非必要源素材。

年龄识别不能只依赖AI猜测。用户声明、订单关系和异常人工复核共同使用，疑似未成年人时先暂停制作。

## 9. 订阅和自动续费

购买前与扣款前的显著提醒至少包含：

- 套餐名称、金额、周期和下次扣款日期；
- 每周期点数、有效期和结转规则；
- 自动续费说明；
- 随时关闭自动续费的路径；
- 取消后当前权益、未用点数、在途任务和已交付内容如何处理；
- 角色工程和云端成品删除日期。

产品要求：

- 在“我的订阅”一级或二级页面提供直接取消；
- 不以联系客服、填写问卷或支付额外费用作为取消条件；
- 扣款提醒记录通知时间、渠道和内容版本；
- 套餐涨价、点数减少或权益变化不应静默作用于已承诺周期；
- 续费失败不重复高频扣款，提供宽限期和支付方式更新；
- 取消成功显示明确生效日期，并可查询记录。

## 10. 定制内容退款与格式条款

购买页必须显著展示：

- 定制主体、动作、数量、格式和许可；
- 角色基准确认的作用；
- 预计工期及暂停工期的情形；
- 包含的修改次数；
- 质量缺陷与需求变更的界线；
- 各制作阶段的取消和退款规则；
- 数字内容下载及设备传输的区别；
- 定制内容是否适用无理由退货及其具体依据和确认方式；
- 售后、投诉和复核渠道。

不建议使用以下绝对条款：

- “定制商品一经付款概不退款”；
- “AI生成效果不承担任何责任”；
- “用户授权平台永久、不可撤销、无限制使用所有照片”；
- “平台可随时修改订阅权益，无需通知”；
- “所有争议均以平台判断为准”。

建议按建角、动作制作、验收和交付拆分价格，使退款可以按未履行部分清晰计算。

## 11. 商品、商标、音乐与声音

### 商品和商标

- 核实提交方是否为权利人或获得授权；
- 明确使用渠道、地区、期限和是否用于广告；
- Logo、包装文字和标准色纳入用户确认及质量检查；
- 不为用户仿制竞争品牌、认证标志或易造成来源混淆的包装。

### 音乐和音效

- 优先使用平台自有或明确覆盖终端设备播放、下载和商业场景的素材库；
- 记录曲目、许可来源、范围和期限；
- 用户上传音乐时要求权利声明，但平台仍需对明显风险进行审核；
- 商用订单单独核实公开表演、信息网络传播及广告等所需权利范围。

### 真人声音

- 声音复刻与普通配音分开；
- 取得声音本人明确、可核验的专项授权；
- 明确文本范围、用途、期限和禁止场景；
- 防止用于诈骗、冒充、金融指令和虚假代言；
- V1建议不开放自助真人声音复刻。

## 12. 上线前法律评审材料包

应向律师提供真实业务材料，而不只是产品介绍：

- 完整用户旅程和页面原型；
- 用户协议、隐私政策、肖像授权和未成年人规则；
- 数据地图：每类数据从App到云端、人工、AI供应商、手机和设备的流向；
- OpenAI、xAI及其他工具的产品形态、合同、DPA和控制台设置；
- 服务器、供应商和用户的主要地区；
- AI显式/隐式标识实现方案与无标识版本计划；
- 内容审核、公众人物、商标、声音和投诉规则；
- 订阅、扣款提醒、取消、点数和退款流程；
