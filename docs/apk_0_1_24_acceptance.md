# 0.1.24 体验验收清单

目标版本：0.1.24+25。构建、签名与文件校验结果见 releases/安装包说明.md。

## 手机体验

1. 覆盖安装后，首页进入日常展示的播放列表，点“添加视频”。未连接硬件也应可选择角色包或手机文件。
2. 从角色包进入已有 Demo，勾选单条视频并添加。列表出现待处理记录，不显示上传成功。
3. 退出列表再进入，待处理记录应保留；切换蓝牙播放列表，不应混入日常展示的待处理记录。
4. 从手机导入视频，调整圆形取景后返回。藏品中不出现独立“本地视频”分区。
5. 点击待处理记录继续取景。如果源文件已失效，应提示重新选择，取消后保留记录。
6. 点击移除先显示确认；取消无变化，确认只移除列表记录。
7. 藏品的内容库可切换官方内容与原创角色；我的角色可查看包内视频。仅有概念图的角色显示暂无可用视频，不编造文件。
8. 在真实设备上播放前查询对应文件；不存在则提示先完成转码上传。

## 明确限制

- 手机文件只保存引用，不保证系统缓存永久存在，不复制到独立媒体库。
- 转码及两套播放列表写入仍有厂家依赖，待处理视频尚不能直接完成硬件上传播放。
- 定制角色未接入真实交付视频清单，不提供原文件导出。
- 体验包使用测试签名；未完成手机安装、原生文件选择器和硬件联调验收。
