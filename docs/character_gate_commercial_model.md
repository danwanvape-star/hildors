# 角色之门：套餐、定价与持续服务模型（V1）

> 最新商业决策：前期原创角色与所有公开原创内容免费，只有面向特定用户的专属定制收费。本文件中的公开内容价格和订阅假设不作为P0方案；执行规则见 [character_gate_free_content_paid_customization.md](./character_gate_free_content_paid_customization.md)。

## 1. 商业原则

角色之门不按“调用了多少次AI”收费，而按用户获得的角色资产、动作内容、人工服务和许可范围收费。

用户应能清楚区分：

- 购买正版角色内容；
- 配置一个已存在的正版角色；
- 创建一个新的原创角色资产；
- 为已有角色增加动作、服装或音乐；
- 订阅持续陪伴与内容权益。

内部AI工具、失败生成次数和人工修复方式不作为用户计价单位。

## 2. 商品体系

### 2.1 正版角色基础包

适用于已授权动漫、游戏、虚拟偶像或合作角色。

建议包含：

- 一个官方形象版本；
- 初次见面动作；
- 3–5个待机动作；
- 一个招牌动作；
- 一个短唱跳或音乐动作；
- 角色护照；
- 指定数量设备的安装许可；
- 明示期限内的重新下载。

这是内容商品，不应收取“定制制作费”。如果用户只选择预制选项，购买后应立即下载。

建议首发价格带：`US$9.99–29.99`，根据IP、内容量、音乐和授权成本分层。

### 2.2 正版角色个性化服务

在授权允许的范围内提供：

- 昵称和称呼；
- 官方服装与配色组合；
- 待机气质和出现频率；
- 纪念日动作；
- 使用官方模板制作的个性欢迎片段；
- 已批准文字或本地字幕。

分为两种：

- **自助配置**：不产生新的角色画面，由系统组合现有内容，可免费或作为角色包权益；
- **制作型个性化**：需要重新渲染、人工修复或真机质检，按次收费。

建议制作型服务价格带：`US$19–59`，不含角色基础包。

### 2.3 原创角色建角

建角费对应建立长期可复用的“角色基准资产”，不是购买几个视频。

交付包括：

- 角色来源与权利预审；
- 正、侧、背角色基准；
- 身体比例和关键细节；
- 设备显示优化版本；
- 角色护照；
- 后续动作制作所需的内部角色工程。

建议三级产品：

| 套餐 | 适合输入 | 交付 | 价格假设 |
|---|---|---|---:|
| OC Lite | 完整设定图或高质量三视图 | 角色基准 + 欢迎 + 3个待机动作 | US$79–149 |
| OC Standard | 单张/多张设定，需要补全 | 完整基准 + 欢迎 + 5个待机 + 招牌动作 | US$199–399 |
| OC Studio | 复杂角色、品牌吉祥物或高要求资产 | 专属评估、较深人工制作和完整动作包 | US$599起 |

首发不应承诺Lite套餐适用于所有输入。素材不足、复杂翅膀、多人、变形角色和精细机械结构应进入人工报价。

### 2.4 个性手办活化

分成两种结果，避免所有用户都为高成本自然动作付费。

#### 数字陈列版

- 保留手办、雕塑、树脂或玩具质感；
- 旋转、镜头移动、微光和轻微生命感；
- 不重构为完全自然的人体运动；
- 制作成本较低，效果更稳定。

建议价格带：`US$49–99`。

#### 角色活化版

- 根据照片重构遮挡区域；
- 对关节、衣摆、武器和头发进行可运动处理；
- 制作欢迎、待机和招牌动作；
- 需要更多人工修复和确认。

建议价格带：`US$149–399`。

第三方动漫或游戏手办只有在Hildors已取得对应数字化授权时才可销售此服务。

### 2.5 动作追加包

| 类型 | 示例 | 定价方式 |
|---|---|---|
| 模板动作 | 挥手、坐下、环顾 | 固定价 |
| 角色专属动作 | 招牌动作、武器表演 | 固定价或复杂度分级 |
| 自定义动作 | 用户描述的新动作 | 先评估后报价 |
| 唱跳动作 | 含音乐和同步 | 内容费 + 音乐许可 |
| 纪念动作 | 生日、相识纪念日 | 模板价或定制价 |
| 双角色动作 | 同台或互动 | 高复杂度专项报价 |

建议价格假设：

- 单个模板动作：`US$4.99–14.99`；
- 一个小型动作包：`US$14.99–39.99`；
- 原创自定义短动作：`US$39–129`；
- 复杂唱跳或双角色：人工报价。

## 3. 免费、付费与人工报价边界

### 免费

- 搜索角色；
- 确认授权状态；
- 提交IP愿望；
- 原创角色可行性预审；
- 查看素材要求；
- 使用示例角色体验设备模拟；
- 保存未付款草稿一段时间。

### 可以立即付款

- 已发布的正版角色基础包；
- 已授权预制动作、服装和音乐包；
- 规则清晰的角色自助配置；
- 输入和交付边界完全标准化的模板服务。

### 必须先报价

- 第三方权利需要核实；
- 单图补全复杂角色；
- 高复杂机械、翅膀、长发、半透明结构；
- 自定义唱跳、战斗、多人或变形动作；
- 商业广告、直播、门店或展会用途；
- 用户要求交付工程文件或跨平台资产；
- 制作周期或修改次数超出标准套餐。

## 4. 报价结构

内部报价公式：

```text
订单价格
= 角色资产建立费
+ 动作与内容制作费
+ 人工修复与质检费
+ 音乐/声音/IP许可费
+ 加急或特殊用途费
+ 支付渠道、税费和风险准备
```

用户端不展示内部小时数，但应展示可理解的价格明细：

- 角色建角；
- 基础行为包；
- 加购动作；
- 音乐或正版内容；
- 特殊用途许可；
- 加急服务；
- 税费。

## 5. 复杂度评分

人工预审使用六个维度，每项0–3分：

| 维度 | 低 | 高 |
|---|---|---|
| 素材完整度 | 完整三视图 | 单图、遮挡或冲突 |
| 角色结构 | 普通人形 | 多臂、翅膀、机械或变形 |
| 材质 | 常规布料 | 玻璃、透明、反射或复杂粒子 |
| 动作 | 待机和挥手 | 唱跳、战斗或多人互动 |
| 权利 | 原创且证明清晰 | 第三方元素或用途复杂 |
| 设备适配 | 清晰大轮廓 | 细线、深色和高速运动 |

建议分流：

- `0–4分`：标准套餐；
- `5–9分`：标准套餐加复杂度附加费；
- `10–14分`：Studio人工报价；
- `15–18分`：专项评估或暂不承接。

复杂度分数仅供内部使用，用户看到的是导致价格变化的具体原因。

## 6. 人工成本控制

每个套餐设置内部工时上限：

- 素材和权利预审；
- 角色基准制作；
- AI生成与筛选；
- 人工修复；
- 设备适配；
- 真机质检；
- 用户沟通和返修。

当预计工时超过套餐上限时，在制作前升级报价，不通过反复调用不同AI工具吸收无限成本。

建议记录：

```text
ai_generation_cost
human_review_minutes
human_edit_minutes
device_qa_minutes
revision_minutes
rights_review_minutes
payment_and_refund_cost
```

单单毛利必须按实际人工和失败成本计算，不能只看模型调用费用。

## 7. 修改与验收权益

### 免费质量修复

- 与已确认角色基准不一致；
- 五官、手部、武器、尾巴或服装明显破损；
- 闪烁、穿模、循环断点或同步异常；
- 设备上出现裁切、比例或播放问题；
- 交付内容缺失。

### 计费需求变更

- 确认后更换角色或风格；
- 更换服装、发型、武器或身体比例；
- 改变动作目标或增加时长；
- 增加音乐、配音、场景或角色；
- 从个人用途扩大到商业用途。

不要使用“定制商品概不退款”。应根据审核、角色基准、动作制作和交付阶段说明已发生的成本与可退金额。

## 8. 订阅模型

订阅不应成为使用已购买角色的前提，也不应在取消后删除已安装内容。

建议采用“角色俱乐部 + 每月权益”，而不是无限生成。

### Free

- 管理已购买角色；
- 本地播放和基础角色记忆；
- 已交付内容继续使用；
- IP许愿和上线通知。

### Character Club（价格假设：US$6.99–9.99/月）

- 每月内容商店额度或折扣；
- 会员待机动作；
- 云端角色护照同步；
- 纪念日和陪伴事件；
- 新角色和内容包提前体验；
- 优先但非无限的定制排期。

### Creator/Collector Plus（后续验证）

- 多设备角色管理；
- 更大的云端资产空间；
- 原创角色动作制作折扣；
- 高级设备预览；
- 创作者委托和收藏展示能力。

订阅取消后：

- 已购买和已交付内容继续在许可范围内使用；
- 会员期内“租用”的内容在到期后停止新增使用，必须购买前明确标识；
- 云同步、会员折扣和未消耗的周期权益按公示规则结束；
- 不远程删除用户单独购买且已安装的内容。

## 9. 角色护照与复购

复购围绕角色生命周期触发，不使用无差别促销：

- 首次唤醒后第3天：推荐一个待机动作；
- 第7天：解锁或推荐角色招牌动作；
- 用户常播放音乐时：推荐已授权音乐包；
- 生日或纪念日前：推荐纪念动作；
- 新服装上线：在对应角色护照内展示；
- 设备长时间未使用：先提示恢复角色待机，不先推销；
- 已完成一个原创角色：推荐动作追加，而不是重新收建角费。

控制通知频率，允许按角色关闭营销通知。

## 10. IP许愿池的商业价值

许愿池不是直接收入商品，而是授权BD的需求数据。

每个愿望记录：

- 作品与角色；
- 用户国家或地区；
- 已拥有或计划购买的设备；
- 最期待的功能；
- 可接受的价格带；
- 是否愿意加入内测；
- 是否愿意接收上线通知。

对外只展示真实且达到隐私阈值的汇总，不制造虚假热度。授权洽谈成功前不预售；如未来采用众筹或意向金，需要单独设计退款和失败处理。

## 11. 首发商品组合

建议不要同时上线大量复杂套餐。P0只保留：

1. `正版角色基础包`：3个角色；
2. `正版角色自助配置`：包含在基础包；
3. `OC Lite申请`：先免费预审再付款；
4. `原创手办数字陈列版`：有限名额；
5. `模板动作追加包`：每个首发角色1组；
6. `IP许愿`：免费；
7. `角色俱乐部`：先作为候补测试，不与P0同时强推。

## 12. 商业验证顺序

### 第一阶段：验证购买理由

观察正版角色包是否提升硬件购买和激活，不急于验证订阅。

### 第二阶段：验证内容复购

观察用户是否为同一角色购买第二个动作、服装或音乐包。

### 第三阶段：验证人工定制毛利

小规模开放OC和手办定制，记录真实工时、返修和价格接受度。

### 第四阶段：验证持续服务

只有在用户已经表现出持续角色需求后，才正式推出角色俱乐部。

## 13. 决策指标

- 角色基础包购买率；
- 每台设备30天角色包数量；
- 第二内容购买率与购买间隔；
- 正版自助配置完成率；
- OC预审到付费转化率；
- 手办数字陈列与活化版的选择比例；
- 单订单AI成本、人工分钟和贡献毛利；
- 首次基准通过率；
- 平均修改轮次；
- 退款和版权拒单率；
- 订阅候补登记率；
- 订阅取消后内容权益投诉率。

## 14. 首发判断

第一阶段最重要的收入不是订阅费，而是：

```text
硬件收入
+ 正版角色基础包
+ 同一角色的第二个内容包
```

原创OC和手办定制应作为限量、高客单、人工可控的增值服务。订阅要等用户已经形成“持续养一个角色”的行为后再推出，否则容易变成没有持续价值支撑的月费。
