# 角色之门：兼职创作者市场与设备限定内容规则（V1）

> 最新商业决策：兼职创作者上架的公开原创角色与内容免费领取；创作者通过平台赏金、活动奖励及付费定制订单获得回报。只有为特定用户单独制作的专属定制收费，详见 [character_gate_free_content_paid_customization.md](./character_gate_free_content_paid_customization.md)。

## 1. 产品定义

角色之门创作者市场包含两种业务：

1. **原创角色上架**：创作者发布自己拥有完整权利的角色和内容包，用户免费领取后在Hildors设备内使用；
2. **定制任务接单**：通过审核的制作师承接用户原创角色、手办和授权角色的建角、动作、修复与设备适配任务。

两个身份分别审核：

- `Original Publisher`：原创角色发行者；
- `Commission Creator`：定制接单制作师。

创作者可以同时申请两种身份，但通过其中一种不自动获得另一种权限。

首发采用邀请制和限量派单，不开放所有用户即时上架、自由报价或私下交易。

## 2. 内容使用模式

用户购买的是设备内播放许可，不获得视频文件所有权或可导出副本。

准确表述：

> 内容会安全传输到用户绑定的Hildors设备中，用户可以在许可范围内离线播放，但不能从App或设备导出原始视频、工程文件或可再分发副本。

“不可下载”不应表述为绝对防复制。产品能够限制正常导出和降低未授权传播，但不能保证内容永远无法被拍摄、破解或复制。

## 3. 创作者准入

P0只接受年满18岁的创作者。

### 通用资料

- 法定姓名或企业名称；
- 创作者公开名称；
- 国家/地区、地址和联系方式；
- 身份验证；
- 收款账户；
- 税务资料；
- 个人、个体经营者或企业身份；
- 是否属于面向消费者经营的交易者；
- 同意平台规则、内容政策和税务报告；
- 作品集和制作工具声明。

面向欧盟消费者提供商品或服务时，平台需要针对适用的交易者可追溯要求收集并尽合理努力验证姓名、地址、联系方式、身份证明、付款账户、商业登记信息及合规自我声明。是否构成“交易者”不能只由创作者自行点击决定，应结合其经营频率、营利目的和专业程度审核。

### Original Publisher附加要求

- 原创角色设定和创作过程；
- 权利链和共同作者信息；
- 外包画师、模型师、配音、音乐和字体许可；
- AI工具、模型、素材和训练/参考来源声明；
- 是否在其他平台独家授权；
- 允许销售的地区、设备、期限和内容类型；
- 商标或品牌权利情况。

### Commission Creator附加要求

- 擅长领域：建角、修图、动画、唱跳、手办活化、设备适配等；
- 标准化测试任务；
- 真机规格考试；
- 交付速度和每周产能；
- 可使用的批准工具；
- 用户资料安全培训；
- 保密与删除义务；
- 质量评分达到门槛。

## 4. 创作者等级

### Candidate

- 只完成测试任务；
- 不接触真实用户订单；
- 不得公开售卖。

### Verified

- 可以接低风险标准订单；
- 每周订单数量受限；
- 所有交付均由平台复核。

### Pro

- 可以接复杂OC、手办和动作任务；
- 可以参与官方授权项目；
- 仍需权利和设备终审。

### Licensed Partner

- 经特定IP方或项目批准；
- 只能在批准项目和品牌规范内制作；
- 项目资格到期不影响其其他普通等级。

等级不是永久荣誉，应根据质量、准时率、投诉、权利记录和安全事件调整。

## 6. 原创角色的权利归属

默认建议：

- 创作者保留其原有角色IP；
- 创作者授予Hildors非独占、可撤销但受已购用户权益约束的分发、加密、设备适配、展示和售后许可；
- Hildors不因角色上架自动取得角色所有权；
- 用户只取得个人、非转让、限定设备的播放许可；
- 平台和其他创作者不得擅自为该角色制作衍生动作，除非上架协议明确允许；
- 已售内容在下架后能否继续播放和重新安装，必须在发布前确定。

如果Hildors购买独家权利或完整转让，必须使用单独合同和单独对价，不能隐藏在通用上架条款中。

## 7. 商店页规则

角色页必须展示：

- 创作者名称和验证状态；
- `原创角色`、`AI辅助`、`人工制作`等准确标签；
- 角色简介和内容预览；
- 包含动作、音乐、时长和空间；
- 支持设备和地区；
- 年龄分级；
- 允许的使用范围；
- 不可导出说明；
- 重新安装和下架后的处理；
- 价格、税费和退款规则；
- 举报和权利投诉入口。

不得使用“官方IP”或容易让用户误解为第三方品牌授权的表达。

## 8. 定制任务接单流程

首发采用平台派单，不做创作者公开竞价。

```text
用户提交并完成平台预审
→ 平台确定权利等级、预算、工期和复杂度
→ 系统推荐2–3名合格制作师
→ 制作师只查看去标识化任务摘要
→ 制作师接受任务
→ 用户付款进入平台托管
→ 平台按最小必要原则开放素材
→ 角色基准制作
→ 平台初审
→ 用户确认
→ 动作制作和人工修复
→ 平台真机质检
→ 用户验收
→ 设备交付
→ 争议期结束后结算
```

制作师不得：

- 引导用户平台外付款；
- 私下索取用户身份、社交账号或额外素材；
- 将用户素材上传到未批准工具；
- 保存、公开或用于作品集展示用户内容；
- 将订单素材用于训练模型；
- 转包给未验证人员；
- 在未获许可时复用角色、动作、音乐或工程资产。

## 9. 派单机制

推荐依据：

- 角色类型和风格；
- 动作与技术能力；
- 已批准工具；
- 权利风险等级；
- 设备型号；
- 历史一次通过率；
- 准时率；
- 当前工作量；
- 用户语言和时区；
- 利益冲突。

平台不能只按最低报价派单，也不应通过暗箱曝光迫使创作者压价。

P0不建议让用户直接挑选几十名创作者。可以向用户展示最终匹配的制作师、作品集、预计时间和价格，并允许一次免费重新匹配。

## 10. 订单里程碑

### M0：任务接受

- 制作师确认范围和工期；
- 平台开放最小必要素材；
- 不立即结算。

### M1：角色基准通过

- 平台先进行质量与权利复核；
- 用户确认后锁定形象；
- 可释放一部分创作者收入。

### M2：动作初版通过

- 检查角色一致性、结构、循环和音乐；
- 用户只针对已确认规格反馈。

### M3：真机交付通过

- 平台完成设备测试；
- 用户验收并安装；
- 进入争议期。

### M4：结算

- 争议期结束；
- 扣除已披露的退款、税费、渠道费和平台分成；
- 向创作者付款并生成结算单。

## 11. 定制订单的权利归属

必须在付款前选择并展示：

### 用户自有角色委托

- 用户保留其原始角色权利；
- 创作者只获得完成订单所需的有限访问和制作许可；
- 新生成的定制成果按合同约定归用户或授予用户排他/非排他使用权；
- Hildors取得设备交付、售后、审核和必要技术处理许可；
- 未经用户独立同意，创作者和平台不得公开作为案例。

### 创作者原创角色的用户加购

- 原角色IP仍归上架创作者；
- 用户获得定制版本的设备播放许可；
- 用户不因购买动作或服装获得原角色所有权；
- 是否允许用户独占某个定制动作，需要单独购买和明确约定。

### 平台已授权IP任务

- 只在IP合同和品牌规范允许的范围内派单；
- 制作师不获得IP权利；
- 成果的归属、保密、销毁和宣传以项目合同为准。

## 12. 不可下载与设备绑定设计

### 用户端规则

- App不提供原视频、透明素材或工程文件导出；
- 商店只播放带水印、降分辨率或缩短的预览；
- 购买后内容加入账户权益库；
- 用户选择已绑定Hildors设备进行安装；
- 设备可以在许可有效期内离线播放；
- 用户换机、维修或设备损坏时，通过受控迁移流程恢复权益。

### 技术链路

```text
创作者上传源文件
→ 平台扫描、审核和转码
→ 生成设备专用内容包
→ 内容包加密并签名
→ 用户购买后生成账户权益
→ 为目标设备签发安装许可
→ App执行受控传输，不暴露可导出文件
→ 设备校验签名和许可
→ 加密存储并离线播放
```

建议能力：

- 每个内容包使用独立内容密钥；
- 设备拥有不可轻易复制的设备身份和密钥；
- 权益服务限制绑定设备数量；
- 设备包签名、防篡改和哈希校验；
- App沙箱和设备安全存储；
- 短期安装凭证与重放保护；
- 迁移、维修、退款和召回状态；
- 预览素材与正式素材分离；
- 下载、安装、离线播放和重新授权审计。

不要只依赖文件改名、隐藏文件夹或关闭分享按钮。这些措施不构成真正的内容保护。

### 离线与授权到期

- 已单独购买的内容，默认应在已授权设备上持续离线播放；
- 订阅租用内容可以设置周期性离线许可，但购买前必须明显说明；
- 创作者主动下架只停止新销售，不应自动删除用户已购买内容；
- 侵权、安全、欺诈或法律命令导致召回时，可以禁止重新下载或续签，并按规则退款；
- 设备长期离线的宽限期、时钟回拨和维修恢复需要工程验证。

## 13. 用户隐私与创作者访问

创作者仅获得完成任务所需的信息：

- 使用平台内项目编号和昵称；
- 默认隐藏用户法定姓名、地址、电话和付款信息；
- 素材在受控工作区查看和处理；
- 下载权限按任务和时间限制；
- 访问、导出和删除操作留审计记录；
- 项目结束后到期回收访问；
- 用户删除请求由平台统一执行并向创作者下达删除任务。

如果当前工具链无法阻止制作师下载源素材，应如实承认并使用合同、最小权限、水印、专用账号、设备管理和审计降低风险，不能向用户承诺“素材绝不会离开平台”。

## 14. 分成建议

所有比例以`Net Receipts`为基础，合同应定义其扣除项目。

### 原创角色商店

首轮测试建议：

- 创作者：70%；
- Hildors：30%。

可从总支付额先扣除并在结算单列明：消费税/VAT、支付渠道费、退款、拒付和依法代扣税款。不能将普通平台运营成本无限加入扣除项。

### 定制接单

首轮测试建议：

- 制作师：70%–80%；
- Hildors：20%–30%。

平台分成覆盖获客、预审、收款、项目管理、权利审核、真机质检、设备交付和售后。高人工平台审核项目可以使用固定平台服务费加创作者制作费，而不是秘密降低创作者分成。

### 结算规则

- 里程碑完成后进入待结算；
- 用户争议期结束后付款；
- 首发可设置合理风险准备金和短期保留期，但必须透明；
- 提供订单级结算单；
- 明确汇率、最低打款额和付款周期；
- 退款按责任和已交付里程碑分配；
- 平台质量问题不能全部转嫁给创作者。

## 15. 税务与创作者身份

- 美国需要判断创作者属于员工还是独立承包人，并按实际支付模式评估1099-NEC、1099-K等信息申报；
- 欧盟DAC7可能要求平台收集、核验并年度报告欧盟卖家的身份和收入信息；非欧盟平台只要在欧盟促成适用活动，也可能需要注册和报告；
- VAT/销售税、预扣税、平台作为merchant of record还是代理收款，需要在支付架构确定后专项设计；
- 不要在产品文案中承诺创作者收入“免税”或由平台统一承担所有税务。

## 16. 内容与权利审核

拒绝：

- 未授权动漫、游戏、影视、名人或品牌角色；
- 从游戏客户端提取的模型、动画、贴图或音乐；
- 不能证明商用权的AI模型、字体、声音和素材；
- 擅自克隆配音演员、用户或公众人物声音；
- 成人色情、未成年人不当内容、仇恨、欺诈和冒充；
- 将其他创作者作品轻微改色后声明原创；
- 删除水印、版权管理信息或伪造来源；
- 含恶意文件、违规脚本或规避设备限制的内容。

建立相似性检测、人工审核、重复侵权者政策、权利人投诉、反通知/申诉和紧急暂停机制。

面向美国运营UGC平台时，应结合实际服务功能评估DMCA安全港，并指定、公开和登记接收版权通知的代理，及时处理有效通知。欧盟还需要结合DSA建立通知、理由说明、申诉和交易者可追溯流程。

## 17. 争议处理

争议类型：

- 用户认为质量不符合基准；
- 用户改变需求但认为应免费；
- 制作师认为补件导致延期；
- 原创角色被投诉抄袭；
- 内容下架或设备许可被暂停；
- 用户和制作师平台外交易；
- 退款、拒付和结算金额争议。

处理原则：

1. 冻结尚未结算的争议金额，不冻结无关收入；
2. 保存订单快照、基准确认、消息、文件版本和质检记录；
3. 由未参与制作的人复核；
4. 区分质量修复、需求变更和权利投诉；
5. 向双方说明决定、依据和申诉入口；
6. 涉及侵权时先控制传播和新销售，再完成正式处理。

## 18. 创作者表现指标

- 接单响应率；
- 准时完成率；
- 角色基准一次通过率；
- 动作真机一次通过率；
- 平均返修轮次；
- S1/S2缺陷率；
- 用户结构化满意度；
- 权利审核退回率；
- 订单争议和退款率；
- 素材安全事件；
- 平台外交易投诉；
- 每小时有效收入。

不建议只使用星级评分决定曝光。新创作者、接复杂订单的人和不同价格带需要校正比较。

## 19. P0上线范围

### 上架侧

- 邀请5–10名原创创作者；
- 每人最多上架1–3个角色；
- 所有角色人工权利审核；
- 所有内容真机质检；
- 统一定价档位，不开放无限自由定价；
- 用户只能在绑定设备播放。

### 接单侧

- 邀请3–5名通过测试的制作师；
- 只开放OC Lite、手办数字陈列和模板动作；
- 平台派单；
- 固定里程碑和修改次数；
- 平台统一与用户沟通，创作者在项目空间回复；
- 每人每周限制并行订单。

### 暂不开放

- 未授权IP接单；
- 创作者私下竞价；
- 用户直接下载成品视频；
- 源文件和工程文件交易；
- 未成年人创作者；
- 真人/声音克隆订单；
- 跨平台导出许可；
- 创作者自行绕过平台真机质检发布。

## 21. 上线闸门

以下任一项未完成，不开放真实创作者交易：

- [ ] 创作者身份、年龄、收款和税务流程；
- [ ] 原创权利证据和AI使用声明；
- [ ] 创作者协议、接单协议和用户许可；
- [ ] 欧盟交易者可追溯与DAC7评估；
- [ ] 美国创作者分类、税务申报和DMCA流程；
- [ ] 内容审核、权利投诉、申诉和重复侵权者规则；
- [ ] 里程碑托管、退款、拒付和结算账本；
- [ ] 用户素材访问、日志和到期删除；
- [ ] 加密设备包、签名、设备绑定和迁移；
- [ ] 创作者测试、真机质检和限量派单；
- [ ] 内容下架、召回和已购用户处理；
- [ ] 运营与客服演练通过。

## 22. 最终建议

首发采用“封闭式创作者工作室”，而不是开放市场：

```text
少量邀请创作者
→ 分别取得上架/接单资格
→ 平台预审和派单
→ 里程碑制作
→ 平台真机终审
→ 加密传入绑定设备
→ 争议期后分账
```

当权利审核、质量、结算和设备保护连续稳定后，再逐步开放自助上架、用户选创作者和更多订单类型。

创作者基础协议、免费原创发布、付费定制接单、订单任务书、成果权利和设备播放许可的签约框架见 [character_gate_creator_contract_framework.md](./character_gate_creator_contract_framework.md)。
