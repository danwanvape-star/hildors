# 角色之门：免费内容＋付费定制商业规则（V1）

## 1. 唯一规则

> 所有可公开领取的角色内容免费；只有为特定用户单独制作的专属定制收费。

用户无需判断角色是否“高级”或某个动作是否属于付费包，只需判断：

- 大家都能领取和安装的公开内容：免费；
- 围绕我的角色、手办或个人需求单独制作：付费。

正版商业IP内容是否继续免费，取决于未来IP合同和平台补贴能力；本规则首先适用于Hildors原创角色和创作者原创内容。若未来正版IP收费，必须与“原创内容免费”清楚分区。

## 2. 免费范围

- Hildors自有原创角色；
- 兼职创作者审核通过的原创角色；
- 公开上架的待机、欢迎、动作和主题包；
- 原创角色的更新内容；
- 免费领取、账户收藏和绑定设备安装；
- 角色护照基础功能；
- IP许愿和上线通知；
- 公开预览与角色发现。

免费内容仍然：

- 不提供视频、透明素材或工程文件导出；
- 只能通过账户权益安装到绑定Hildors设备；
- 经过原创权利、内容安全和真机质量审核；
- 受设备数量、地区、年龄和使用许可约束；
- 保留投诉、下架、召回和重新安装规则。

## 3. 付费范围

只有产生专属人工服务和专属结果的定制收费：

- 用户OC建角；
- 原创手办数字化或角色活化；
- 为用户已有角色制作专属动作；
- 专属欢迎、纪念日、服装或道具；
- 用户提供合法音乐后的定制唱跳；
- 品牌吉祥物和商业展示；
- 复杂修复、多角色、加急和特殊设备适配；
- 用户独占或限制他人使用的定制成果。

付费定制不等于用户获得可下载视频。默认仍交付账户权益和绑定设备播放许可；如未来提供源文件或跨平台许可，必须作为完全不同的高价商业产品和合同处理。

## 4. 免费内容的领取流程

```text
浏览原创角色
→ 点击“免费领取”
→ 确认设备播放许可
→ 写入账户权益
→ 选择绑定设备
→ 获取短期安装凭证
→ 加密内容包传入设备
→ 首次播放并加入角色护照
```

不使用`$0购买`，使用`免费领取`。即使免费，也不能把正式文件放在公开下载地址。

## 5. 付费定制流程

```text
提交原创角色或手办
→ 免费可行性和权利预审
→ 明确交付物、价格和工期
→ 用户付款
→ 平台派单给合格制作师
→ 角色基准确认
→ 制作、人工修复和真机质检
→ 用户验收
→ 绑定设备交付
→ 争议期后向制作师结算
```

搜索角色、判断是否能做、素材初检和报价本身不收费。平台只在确认可承接并展示完整报价后收款。

## 6. 创作者收入

### 上架原创免费内容

由于用户不付款，不采用销售分成。平台可以提供：

- 入选固定赏金；
- 完成设备适配奖励；
- 有效安装里程碑奖金；
- 30日真实播放奖励；
- 主题征集奖金；
- 测试硬件、AI制作额度和官方认证；
- 获得付费定制接单资格和曝光。

免费上架也可以完全自愿，但必须在提交前明确是否有奖金，不能以模糊的“未来曝光”代替已承诺报酬。

### 承接专属定制

制作师按订单获得收入。建议测试：

- 制作师获得定制净收入的70%–80%；
- Hildors获得20%–30%，覆盖预审、项目管理、支付、权利审核、真机质检、设备交付和售后。

平台也可以使用“固定平台服务费＋制作师报价”，让用户更清楚钱支付给了谁。

## 7. 免费内容质量机制

不因免费降低标准。每个公开内容必须通过：

- 创作者身份和年龄验证；
- 原创证据和共同作者确认；
- AI工具、模型和素材声明；
- 音乐、声音、字体和动作权利；
- 相似性和疑似抄袭检查；
- 内容安全和年龄分级；
- 包签名、设备适配和真机质检。

低质量内容不应以“反正免费”为理由进入商城，否则会降低硬件价值。

## 8. 首页与商城文案

定制入口：

> 免费收藏原创角色，为你的OC或手办购买专属定制。

原创商城按钮：`免费领取`

定制按钮：`免费预审并获取报价`

订单付款按钮：`确认定制并支付 {amount}`

设备提示：

> 免费或付费内容都会加入你的角色库，并安装到绑定的Hildors设备；不提供原视频导出。

## 9. 商城信息架构

建议分成两个一级入口：

### 免费角色库

- 原创角色；
- 免费动作；
- 最新上架；
- 热门安装；
- 编辑推荐；
- 新人创作者。

### 专属定制

- 创建我的OC；
- 活化我的手办；
- 为已有角色增加动作；
- 查看制作师和示例；
- 我的定制订单。

不要把免费角色和付费服务混在同一个价格筛选列表中。

## 10. 指标

### 免费内容

- 浏览到领取转化率；
- 领取到成功安装率；
- 首次播放完成率；
- 每台设备领取角色数；
- 7日/30日真实播放设备数；
- 免费角色对硬件激活和留存的提升；
- 每个有效安装的补贴与审核成本。

### 付费定制

- 免费预审到报价率；
- 报价到付款率；
- 角色基准一次确认率；
- 平均人工分钟和交付周期；
- 真机一次通过率；
- 返修、退款和争议率；
- 单笔定制毛利；
- 完成定制后的角色播放留存。

不要用原创内容收入作为前期指标，因为原创公开内容本身不收费。

## 11. P0建议

- 上线10–20个免费原创角色；
- 每个角色至少包含欢迎、3个待机和1个招牌动作；
- 邀请5–10名原创发行者；
- 邀请3–5名付费定制制作师；
- 只开放OC Lite、原创手办数字陈列和模板化专属动作；
- 所有免费与付费内容均不可导出，只能绑定设备播放；
- 创作者免费内容使用固定赏金或活动奖金；
- 付费定制使用里程碑托管和订单分成；
- 每周限制付费定制并行订单，按真实人工产能扩容。

## 12. 最终商业结构

```text
免费原创角色和公开内容
→ 丰富设备内容并提高活跃
→ 用户建立角色偏好与信任
→ 用户提出自己的OC、手办或专属动作需求
→ 购买付费定制
→ 兼职制作师获得订单收入
→ 更多创作者贡献免费角色
```

这个模型的收入核心不是“卖每一条视频”，而是为用户提供高质量、可验收、可以持续维护的专属角色服务。
