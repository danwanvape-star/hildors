# 角色之门：MVP开发清单与验收标准（V1）

## 1. MVP目标

P0需要证明两个闭环：

### 免费内容闭环

```text
发现免费原创角色
→ 免费领取到账户
→ 安装到绑定设备
→ 成功首次播放
→ 进入角色护照
```

### 付费定制闭环

```text
提交原创角色/手办
→ 免费预审
→ 报价与付款
→ 平台派单
→ 角色基准确认
→ 制作与真机质检
→ 用户验收
→ 绑定设备交付
→ 创作者结算
```

MVP不以开放市场规模为目标，只支持少量受邀创作者和限量订单。

## 2. 当前工程可复用能力

| 当前模块 | 可复用 | 需要调整 |
|---|---|---|
| `CustomizationPage` | 现有导航入口 | 从照片流程改成角色之门双入口 |
| `CommunityPage` | 内容列表、详情入口 | 增加免费领取、原创/创作者/设备标签 |
| `ContentPreviewPlayer` | 角色内容预览 | 只使用预览资产，不接触正式包 |
| `ContentDownloadService` | 进度回调接口形式 | 从模拟下载升级为权益和安装会话驱动 |
| `ExperiencePackManifest` | 包版本、设备和文件概念 | 增加角色、权利、签名、哈希和许可字段 |
| `P20UploadTaskState` | 分包确认、失败和取消状态 | 外层增加安装会话、权益、签名和设备回执 |
| `ProjectionService` | 指定播放基础 | 增加权益内容播放和首次唤醒结果 |
| `HolopetProfile/State` | 陪伴状态设计参考 | 抽象成通用角色护照，不直接混用宠物模型 |

## 3. Epic A：角色之门入口

### CG-001 替换定制中心首屏

实现：

- 品牌标题与定位；
- `免费原创角色`入口；
- `专属定制`入口；
- `角色许愿`入口；
- 免费与付费边界说明；
- 草稿恢复入口。

验收：

- [ ] 首屏不再以人物、宠物、商品照片为主；
- [ ] 用户能在30秒内说清什么免费、什么收费；
- [ ] 未接后端时展示真实“即将开放”状态，不弹出误导性错误；
- [ ] 三个入口都有独立路由和分析事件；
- [ ] 320px宽度无溢出或按钮遮挡。

### CG-002 角色来源分流

选项：免费角色库、我的原创角色、原创手办、品牌角色、喜欢的游戏/动漫角色、不确定。

验收：

- [ ] 第三方游戏/动漫选择不能进入付款；
- [ ] 原创路径先进入免费预审；
- [ ] 未授权角色进入许愿；
- [ ] 选择和解释自动保存；
- [ ] 不记录不必要的自由文本到分析系统。

## 4. Epic B：免费原创角色库

### CG-101 免费角色列表

字段：角色、创作者、预览、类型、年龄分级、支持设备、领取状态和设备实测状态。

验收：

- [ ] 所有P0公开原创内容显示`免费领取`而非价格；
- [ ] 不显示`免费下载`；
- [ ] 原创、AI辅助、创作者和设备实测标签准确；
- [ ] 空状态、加载、失败和地区不可用状态完整；
- [ ] 预览资源与正式资源使用不同URL和权限。

### CG-102 角色详情

验收：

- [ ] 展示角色来源、创作者、动作、设备和许可摘要；
- [ ] 明确正式内容不可导出；
- [ ] 未领取、已领取、可安装、已安装状态使用不同CTA；
- [ ] 有举报和权利投诉入口；
- [ ] 普通下架、权利暂停和安全召回状态分开。

### CG-103 免费领取

验收：

- [ ] 用户确认设备播放许可；
- [ ] 服务端以幂等接口创建零价权益；
- [ ] 重复点击不会创建重复权益；
- [ ] 领取失败不会显示成功；
- [ ] 领取后角色进入权益库，不自动假装安装完成；
- [ ] 领取事件与安装事件分开统计。

### CG-104 角色收藏库

验收：

- [ ] 显示已领取、未安装、安装中、已安装和不可用状态；
- [ ] 支持按绑定设备查看；
- [ ] 免费内容与付费定制内容不以价格区分权限；
- [ ] 无原始视频导出、分享或文件路径入口；
- [ ] 可以查看许可、重新安装和下架说明。

## 5. Epic C：设备绑定和受控安装

### CG-201 设备登记

验收：

- [ ] 设备ID与账户绑定；
- [ ] 同一设备异常绑定多个账户时进入验证；
- [ ] 展示设备型号、固件、空间和在线状态；
- [ ] 解绑前说明已安装内容和迁移影响；
- [ ] 敏感设备凭证使用系统安全存储。

### CG-202 安装会话

状态：权益检查、设备检查、许可证、下载、清单验证、传输、设备验证、索引、首次播放、完成。

验收：

- [ ] 未领取账户不能开始安装；
- [ ] 错误设备或超出设备数量不能安装；
- [ ] 客户端不能伪造权益、地区或包版本；
- [ ] 文件使用短期票据；
- [ ] 包哈希或签名错误时停止；
- [ ] 网络/蓝牙中断后能从安全节点恢复；
- [ ] 购买/领取、下载、传输和播放是独立状态；
- [ ] 只有设备回执成功才记录安装完成。

### CG-203 App私有缓存

验收：

- [ ] 正式包不写入公共Downloads、相册或媒体库；
- [ ] 不注册系统分享入口；
- [ ] 安装成功或超时后按策略清理；
- [ ] 退出账号后清理不再可用的缓存；
- [ ] 日志不包含完整签名URL、密钥或用户素材路径。

### CG-204 固件级许可证（正式开放市场闸门）

验收：

- [ ] 每台设备具有不可直接复制的身份；
- [ ] 设备验证包签名和设备许可证；
- [ ] 不匹配设备拒绝内容；
- [ ] 正式内容不以长期明文保存；
- [ ] 换机、维修、离线和召回策略有实机测试；
- [ ] 无法达到上述条件时，产品只宣称“受控安装”，不宣称强DRM。

## 6. Epic D：专属定制用户端

### CG-301 免费预审申请

支持：原创OC、原创手办、品牌角色和已有角色动作。

验收：

- [ ] 预审前不要求付款；
- [ ] 输入类型决定素材清单；
- [ ] 显示文件用途和保存期限；
- [ ] 自动检查给出可操作补件建议；
- [ ] 疑似第三方IP暂停，不绕过进入报价；
- [ ] 用户可以保存和删除未提交草稿。

### CG-302 人工预审结果

结果：可报价、需要补件、无法承接、需要权利升级。

验收：

- [ ] 每个结果说明具体原因和下一步；
- [ ] 无法承接时没有支付按钮；
- [ ] 未授权IP提供许愿入口；
- [ ] 补件保留原申请状态；
- [ ] 预审决定和证据有审计记录。

### CG-303 报价与支付

验收：

- [ ] 报价包含角色基准、动作、人工、设备适配、许可、工期和修改次数；
- [ ] 保存不可变报价快照；
- [ ] 用户确认没有源视频/工程文件导出；
- [ ] 支付成功由服务端回调确认；
- [ ] 客户端成功页不直接创建已付款状态；
- [ ] 重复回调和刷新保持幂等。

### CG-304 角色基准确认

验收：

- [ ] 展示参考、制作基准和设备模拟；
- [ ] 支持最多5项锁定细节；
- [ ] 区分质量不一致和新需求；
- [ ] 确认后保存版本、时间和条款；
- [ ] 新需求创建变更单，不覆盖原订单。

### CG-305 订单时间线

验收：

- [ ] 显示当前阶段、预计更新和下一责任人；
- [ ] 等待用户操作时突出唯一CTA；
- [ ] 不显示GPT、Grok等内部工具；
- [ ] 延期显示新日期和原因；
- [ ] 消息、文件版本和正式确认分开。

### CG-306 验收与反馈

验收：

- [ ] 使用结构化问题类型；
- [ ] 质量问题不消耗需求变更次数；
- [ ] 需求变化进入重新报价；
- [ ] 最终验收记录对应文件版本；
- [ ] 验收后可以启动设备安装；
- [ ] 用户沉默不自动视为同意，除非已完成专项合法设计。

## 7. Epic E：创作者端

### CG-401 双资格申请

验收：

- [ ] 原创发行和定制接单分别选择和审核；
- [ ] 创作者必须年满18岁；
- [ ] 公开名称和法定身份分开；
- [ ] 身份、收款和税务状态独立；
- [ ] 未完成必要审核不能发布或接单；
- [ ] 记录接受的协议版本。

### CG-402 原创角色提交

验收：

- [ ] 提交角色基准、内容包、原创证据和AI声明；
- [ ] 共同作者、第三方素材、音乐、声音和字体独立填写；
- [ ] 明确用户免费领取；
- [ ] 明确创作者是否允许其他制作师接定制；
- [ ] 历史版本不能覆盖；
- [ ] 审核问题指向文件和时间点。

### CG-403 平台派单

验收：

- [ ] 接受前只展示去标识化摘要；
- [ ] 显示制作师报酬、工期、范围和修改次数；
- [ ] 接受使用原子状态，不能多人重复接单；
- [ ] 合理拒单不自动处罚；
- [ ] 接单后才授予任务素材权限；
- [ ] 并行订单数量受等级限制。

### CG-404 项目工作区与里程碑

验收：

- [ ] 只显示完成任务所需素材；
- [ ] 任务访问有到期时间；
- [ ] 里程碑提交不能由聊天代替；
- [ ] 每次提交包含版本、工具、来源和已知问题；
- [ ] 超范围需求使用变更申请；
- [ ] 任务结束后访问自动回收。

### CG-405 奖励与收入

验收：

- [ ] 免费内容奖励和定制收入使用两个视图；
- [ ] 每笔记录显示公式、扣除和预计支付日；
- [ ] 账本只追加，调整使用反向记录；
- [ ] 只冻结争议订单金额；
- [ ] 税务或收款问题说明补救步骤；
- [ ] 可以导出结算单，但不能导出用户交付内容。

## 10. 数据与分析

必须分开的事件：

```text
character_viewed
free_claim_started
free_claim_completed
install_started
package_verified
device_transfer_completed
device_install_confirmed
first_play_completed
passport_opened
custom_review_submitted
quote_viewed
custom_payment_completed
baseline_approved
delivery_approved
creator_job_accepted
milestone_approved
creator_payout_released
```

禁止将`free_claim_completed`当作角色真正被使用。核心使用指标以设备安装回执和真实播放为基础。

## 13. 建议开发顺序

```text
1 角色之门入口和本地原型
2 服务端角色目录与免费权益
3 设备绑定、安装会话和失败恢复
4 定制免费预审、报价和订单时间线
5 创作者双资格、角色提交和运营审核
6 派单、里程碑、账本和结算
7 固件级内容加密与设备许可证
8 封闭创作者和真实付费定制测试
```

不要先开发自由竞价、粉丝社交、复杂推荐和创作者等级动画。这些不影响两个核心闭环成立。
