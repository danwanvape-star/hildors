# Hildors 定制服务数据地图、保存与删除规范（V1）

> 本文件是产品和技术实施基线。具体法定保存期限、跨境路径及删除例外应由法律、财税和隐私负责人结合业务主体、销售地区及实际供应商确定。

## 1. 数据流总览

```text
用户 App
  ├─ 账号、联系方式 ─────────────→ 账号服务
  ├─ 照片/声音/授权证明 ─────────→ 源素材区
  ├─ 需求、用途、授权选择 ───────→ 订单与授权服务
  └─ 支付操作 ──────────────────→ 支付渠道

订单与授权服务
  ├─ 通过授权/风险检查 ──────────→ 生产编排服务
  └─ 不通过 ────────────────────→ 补件 / 拒绝 / 删除任务

源素材区
  ├─ 最小必要素材 ───────────────→ 已批准 AI 工具
  ├─ 必要素材 ──────────────────→ 授权制作人员
  └─ 身份/授权证明 ─────────────→ 仅授权审核人员，不进生成工具

AI 工具 / 人工制作
  └─ 生成结果和中间工程 ─────────→ 生产隔离区

生产隔离区
  ├─ 自动校验与人工质检不通过 ───→ 返工 / 到期删除
  └─ 通过 ──────────────────────→ 用户预览区

用户确认
  ├─ 退回修改 ──────────────────→ 新生产版本
  └─ 验收通过 ──────────────────→ 正式发布区

正式发布区
  ├─ 下载 ──────────────────────→ 用户手机本地
  └─ 设备包 ────────────────────→ P20 / P11 本地存储
```

支付渠道、外部AI供应商、云存储和通知服务均应在数据接收方清单中单独登记。

## 2. 数据域与唯一标识

| 数据域 | 主键建议 | 关联关系 |
|---|---|---|
| 用户 | `user_id` | 订单、角色、订阅、权利请求 |
| 订单 | `order_id` | 需求、授权、素材、生产、支付、售后 |
| 角色 | `character_id` | 主体、基准版本、视频、订阅 |
| 需求版本 | `requirement_version_id` | 用户确认、报价、生产工作流 |
| 授权 | `consent_record_id` | 用户、订单、政策版本、范围 |
| 素材 | `asset_id` | 来源、派生关系、存储、保存期限 |
| 生产任务 | `production_task_id` | 工具、输入、输出、成本、操作者 |
| 质检 | `review_id` | 产物、评分、缺陷、审核员 |
| 设备包 | `package_id` | 成品、设备规格、文件哈希 |
| 设备安装 | `installation_id` | 包、设备、本地状态和时间 |
| 权利请求 | `privacy_request_id` | 查阅、更正、撤回、删除、注销 |

不要用用户姓名、手机号码或原始文件名作为跨系统关联键。

## 3. 数据分类

### D0 公开或通用配置

示例：动作模板、设备公开规格、套餐名称、通用帮助文案。

控制：可进入普通日志和缓存，但发布版本仍应可追溯。

### D1 内部业务数据

示例：订单状态、成本汇总、非敏感运营指标、工具工作流版本。

控制：员工登录、岗位权限、操作日志；不得公开。

### D2 个人信息和用户内容

示例：账号、联系方式、自由文本需求、宠物照片中可识别的家庭背景、用户生成成品。

控制：按业务需要访问，加密传输和存储，限制日志及导出。

### D3 高保护数据

示例：可识别人物原图、面部特征、声音样本、未成年人资料、身份或授权证明、精确地址和支付账户信息。

控制：独立存储域、最小权限、短期访问地址、下载审批、完整审计、严格保存期限和删除验证。

技术系统按最高等级继承：包含 D3 图片的压缩包、中间工程或 Prompt 均按 D3 管理。

## 4. 数据清单与V1保存建议

| 数据 | 等级 | 主要目的 | 可访问角色 | 建议保存策略 |
|---|---|---|---|---|
| 账号和联系方式 | D2 | 登录、通知、售后 | 客服受限、账号系统 | 账号期内；注销后按必要性删除/去标识 |
| 订单和需求快照 | D1/D2 | 履约、争议、售后 | 客服、制作必要字段、售后 | 按合同、财税及争议需要确定 |
| 支付交易记录 | D2/D3 | 对账、退款、法定义务 | 财务、售后受限 | 由财税和支付要求确定，不与照片混存 |
| 人物原始照片 | D3 | 审核和制作 | 审核、获批制作员 | 非订阅建议验收后30天；法律审核后配置 |
| 宠物/商品照片 | D2；含人物背景时升D3 | 制作 | 审核、制作 | 非订阅建议验收后30天 |
| 未成年人照片 | D3 | 专项定制 | 专项审核、指定制作员 | 从严，任务结束后尽快删除非必要副本 |
| 声音样本 | D3 | 声音制作 | 专项人员 | 与声音授权绑定，V1默认不收集 |
| 身份/监护/商标证明 | D3 | 权利审核 | 审核、法律/售后受限 | 不进入制作区；期限由必要性和争议需求确定 |
| 授权记录 | D2/D3 | 证明同意范围 | 隐私、售后受限 | 至少覆盖内容使用和潜在争议期，律师确定 |
| Prompt及参数 | 随输入继承 | 复现、审计 | 制作、技术受限 | 不长于相关源素材，除非彻底去标识 |
| AI输入副本 | 随输入继承 | 外部调用 | 系统、必要技术人员 | 调用完成尽快清理；供应商期限单独登记 |
| 模型输出/失败结果 | D2/D3 | 筛选、返工 | 制作、质检 | 未发布失败产物建议订单关闭后30天内删除 |
| 角色基准和工程 | D2/D3 | 持续制作 | 制作、质检 | 订阅期 + 30天恢复窗口；以用户选择为准 |
| 用户预览 | D2/D3 | 验收 | 用户、客服、质检 | 验收或售后结束后按短期策略删除 |
| 最终成品 | D2/D3 | 用户交付 | 用户、客服受限 | 按购买页承诺；取消订阅后至少保留既定下载窗口 |
| 设备包 | D2/D3 | 下载和传输 | 用户、发布服务 | 与成品策略一致，按型号和版本管理 |
| 手机本地文件 | 用户设备 | 离线传输 | 用户 | 由用户删除；App提供缓存管理 |
| P20/P11设备文件 | 用户设备 | 本地播放 | 用户 | 不因订阅取消远程删除 |
| 生产及访问日志 | D1/D2 | 安全、追溯、成本 | 安全、技术、审计 | 期限按风险与法规要求配置；不写原始敏感内容 |
| AI标识相关日志 | D1/D2 | 标识追溯 | 合规、技术 | 无显式标识等适用场景需满足对应最低期限 |
| 客服和售后记录 | D2 | 争议处理 | 客服、售后 | 按售后及争议需要确定 |

表中“30天”是产品建议，不是对法定期限的判断；正式上线时每一项必须填写最终期限、依据、起算事件和删除方式。

## 5. 保存策略配置模型

```text
RetentionPolicy
  policy_id
  data_category
  subject_type
  service_type
  jurisdiction
  trigger_event               // uploaded | rejected | accepted | subscription_ended
  active_retention_days
  recovery_days
  backup_expiry_days
  legal_hold_supported
  deletion_method
  external_processors
  policy_version
  approved_by
  effective_at
```

保存期限必须从明确事件起算，例如“用户验收完成后30天”，不能仅写“短期保存”。

## 6. 素材状态机

```text
uploaded
  → quarantined
  → reviewed
  → approved_for_production
  → in_production
  → retained_for_revision
  → deletion_scheduled
  → deleting
  → deleted
```

异常状态：

- `blocked`：授权不足、违规或安全风险；
- `legal_hold`：存在投诉、争议或其他经批准的保留原因；
- `deletion_failed`：部分系统或供应商删除失败；
- `orphaned`：找不到有效订单或角色关联，需要隔离调查。

处于 `deletion_scheduled`、`deleting` 或 `deleted` 的素材不能创建新生产任务。

如果供应商的网页端、API和企业版使用不同数据条款，应建立不同记录。

## 8. 访问权限

### 8.1 默认权限

| 角色 | 人物原图 | 授权证明 | Prompt | 中间工程 | 成品 | 支付记录 |
|---|---:|---:|---:|---:|---:|---:|
| 客服 | 受限缩略图 | 仅状态 | 否 | 否 | 预览 | 仅状态/金额 |
| 审核员 | 是 | 是 | 否 | 否 | 必要时 | 否 |
| AI制作员 | 经批准 | 否 | 是 | 是 | 是 | 否 |
| 后期制作员 | 经批准 | 否 | 必要摘要 | 是 | 是 | 否 |
| 质检员 | 对比所需 | 仅审核状态 | 否 | 必要版本 | 是 | 否 |
| 售后 | 争议所需 | 争议所需 | 否 | 必要时 | 是 | 退款所需 |
| 财务 | 否 | 否 | 否 | 否 | 否 | 是 |
| 系统管理员 | 默认否 | 默认否 | 默认否 | 默认否 | 默认否 | 默认否 |

系统管理员能维护系统不代表默认能浏览业务内容。紧急访问使用临时提权、审批、时间限制和审计。

### 8.2 原图下载

原图默认只在受控网页查看。必须下载时：

1. 选择订单与业务原因；
2. 检查当前授权及素材状态；
3. 生成短期、单次或有限次数下载地址；
4. 记录人员、设备、IP、时间和文件；
5. 展示本地清理期限；
6. 完成任务后确认清理。

严禁通过个人微信、个人邮箱或个人网盘中转。

## 9. 权利请求流程

支持：查阅、复制、更正、补充、撤回同意、删除、限制处理、注销和查询授权记录。

```text
用户提交请求
  → 身份核验
  → 确定请求范围
  → 查找相关用户、订单、角色、素材和接收方
  → 判断可立即执行 / 需要补充 / 存在经批准例外
  → 执行各系统任务
  → 验证结果
  → 向用户反馈
  → 保存不含原始敏感内容的处理记录
```

不得要求用户提供超出核验所需的额外身份资料。拒绝或延迟处理必须有依据、负责人和申诉路径。

## 10. 撤回同意影响矩阵

| 撤回项目 | 新任务 | 在途任务 | 已交付内容 | 后台处理 |
|---|---|---|---|---|
| 案例展示 | 立即停止新增使用 | 停止待发布案例 | 用户自己的成品不受影响 | 下架未来展示，记录处理进度 |
| AI改进 | 不再进入改进数据集 | 未合并部分移除 | 交付不受影响 | 通知相关数据管道 |
| 云端角色保存 | 不允许新动作复用 | 与用户确认继续或终止 | 已交付内容保留 | 安排源素材/工程删除 |
| 向特定第三方提供 | 不再发送该第三方 | 暂停任务并评估替代 | 已交付内容按许可处理 | 请求第三方删除适用数据 |
| 肖像制作授权 | 不开始新制作 | 暂停并由法律/售后判断 | 依合同、撤回和已履行情形处理 | 冻结相关角色并保留必要证据 |

撤回后的具体法律效果不能只由代码自动裁定。涉及肖像许可、已支付履约或争议时应进入人工处理。

## 11. 删除范围

删除一个角色源素材时，系统必须查找：

- 原始上传文件；
- 缩略图、转码图、裁剪图和缓存；
- 角色参考图与未发布基准；
- Prompt中的可识别描述；
- AI供应商任务和文件对象；
- 制作人员下载副本及共享目录；
- 未发布视频和中间工程；
- CDN或短期下载地址；
- 搜索索引、向量或特征数据；
- 备份中的对应过期计划；
- 分析、日志和客服附件中的异常副本。

删除成品与删除源素材分开。用户可以删除源照片但保留已经交付的视频，前提是许可和争议状态允许。

## 13. 第三方删除

- 调用供应商删除 API 或企业控制台操作；
- 保存供应商任务 ID、请求时间和确认结果；
- 供应商只支持按账号删除时，评估是否适合处理多用户生产数据；
- 供应商无法按订单删除时，在准入评分中降低等级并限制数据类型；
- 超时未确认时进入 `deletion_failed`，自动告警并转人工；
- 不能把“本地已删除”作为供应商也已删除的证明。

## 14. 备份处理

- 生产删除后，备份不应继续供业务查询或恢复单个用户数据；
- 备份设置固定过期周期并加密、限制访问；
- 从备份执行灾难恢复时，重新应用恢复点之后的删除清单；
- 删除完成反馈说明备份的隔离和到期机制；
- 法律/隐私负责人确认是否需要更快的特定数据清理能力。

## 15. 法律保留

只有授权角色可以设置 `legal_hold`，必须记录：

- 适用对象和具体数据范围；
- 原因和批准人；
- 开始、复审和预计解除日期；
- 为什么不能使用更小的数据范围；
- 解除后自动恢复删除流程。

不能以“以后可能有用”作为法律保留理由，也不能借法律保留长期保存全部原始照片。

## 16. 日志最小化

日志中禁止写入：

- 原始照片或声音内容；
- 身份证明完整内容；
- 长期有效文件地址；
- API密钥、访问令牌和支付凭证；
- 完整Prompt中的个人信息；
- 用户电话号码、地址和身份证号码明文。

日志只记录ID、事件类型、结果、原因码、操作者和必要时间。排障需要内容时使用受控临时访问，而不是扩大普通日志采集。

## 17. AI标识数据

每个最终成品至少关联：

```text
AIGCProvenance
  content_id
  is_ai_generated_or_edited
  creation_service_identifier
  workflow_version
  visible_label_mode
  invisible_label_version
  metadata_written_at
  export_variant
  no_visible_label_request_id
  label_verification_result
```

转码、重新打包和设备适配后重新验证隐式标识。若设备格式不能保留文件元数据，应由合规、硬件和产品共同设计替代机制，不能静默丢失。

## 18. 定期任务

每日：

- 执行到期删除；
- 重试失败的第三方删除；
- 检查过期短期地址和孤立文件；
- 告警无订单关联的生产素材。

每周：

- 复核高权限访问和原图下载；
- 检查到期但仍被任务引用的素材；
- 处理权限请求超时；
- 抽查制作人员本地文件清理记录。

每月：

- 对账存储清单与数据库资产记录；
- 复核供应商保留和删除能力；
- 抽查备份恢复后删除清单可重放；
- 检查日志和埋点是否出现敏感字段；
- 复核角色工程和取消订阅恢复窗口。

## 19. 验收用例

- [ ] 未授权订单的照片不能生成AI生产任务；
- [ ] 身份/授权证明不能被发送给生成工具；
- [ ] 同一用户不同订单的授权不会被默认复用；
- [ ] 原图下载需要原因、短期地址并产生审计；
- [ ] 用户撤回案例展示后，后续案例发布被阻止；
- [ ] 用户撤回云端保存后，角色源素材按流程进入删除；
- [ ] 删除任务覆盖缩略图、缓存、中间工程和外部供应商；
- [ ] 第三方删除失败时请求不会误标为完成；
- [ ] 处于删除中的素材不能被新工作流引用；
- [ ] 灾难恢复后已删除素材不会重新进入业务可用状态；
- [ ] 日志和埋点不包含原图、完整Prompt、密钥和永久文件地址；
- [ ] 取消订阅不会远程删除手机或P20/P11上的已交付内容；
- [ ] 转码和设备打包后AI隐式标识仍能验证；
- [ ] 法律保留有范围、批准、复审和解除时间；
- [ ] 用户能查询权利请求状态和最终处理结果。

## 20. 上线前待填写项目

- 公司个人信息处理者主体与联系方式；
- 数据保护、投诉和安全事件负责人；
- 每类数据的最终保存期限及依据；
- 国内云存储、CDN、支付和通知供应商；
- OpenAI、xAI及其他AI工具的合同主体、地区、DPA和删除能力；
- 是否存在向境外提供个人信息及采用的合规路径；
- 用户权利请求的服务时限；
- 备份周期、隔离方式和删除重放机制；
- AI显式/隐式标识的技术标准及设备兼容方案；
- 法律保留批准人和争议数据最小范围。
