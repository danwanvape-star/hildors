|---|---:|---|

| 播放/暂停 | `0x02` | 可实现 |
| 第一条/上一条/下一条 | `0x03` | 可实现 |
| 查询/设置亮度 | `0x04` / `0x05` | 可实现 |
| 查询/设置角度 | `0x06` / `0x07` | 可实现，单位及安全范围待确认 |
| 查询/设置播放模式 | `0x08` / `0x09` | 可实现 |
| 查询运行状态 | `0x0F` | 可实现 |
| 设备热点名称 | `0x21` / `0x22` | 可实现 |
| 路由 Wi-Fi | `0x23` / `0x24` | 可实现 |

| 恢复出厂参数 | `0xE1` | 可实现，危险操作 |
| 设备版本 | `0xE8` | 可实现 |

## 新版协议必须补充

| 能力 | 最低需要的数据 |
|---|---|
| 当前工作模式 | 本机播放/蓝牙等待/蓝牙播放及主动上报 |
| 模式切换 | 目标模式、执行结果和失败原因 |
| 蓝牙可发现 | 当前状态、设置结果和剩余可发现时间 |
| 蓝牙连接 | 连接状态、音源名称/地址和断开原因 |
| 蓝牙音频 | 播放、暂停、无音频及主动状态上报 |
| 音量和静音 | 当前值、有效范围、设置应答 |
| 蓝牙状态视频 | 当前文件、设置文件及恢复默认 |
| 蓝牙断开策略 | 恢复本机/播放首条/保持等待 |
| 色彩模式 | 模式列表、当前模式及设置结果 |
| 状态灯 | 当前状态及设置结果 |
| 上电启动策略 | 自动播放开关、默认视频或播放列表 |
| 存储状态 | 总容量、可用容量和视频占用 |
| 电池状态 | 电量百分比、充电状态、低电量事件、电池异常及主动上报 |

## 协议设计建议

- 查询和设置使用独立命令，或明确区分请求字段。
- 每个设置应答返回原值、目标值和结果码。
- 模式、蓝牙连接和故障变化应由 P20 主动上报，不依赖 App 高频轮询。
- 所有主动上报使用独立事件命令范围，避免与请求应答队列冲突。
- 增加协议版本和硬件能力位图，使 App 能兼容不同批次设备。
- 增加请求序号；如果无法改帧格式，同一 CMD 必须限制为串行请求。
- 明确字符串编码、超时、重试、最大帧长及 TCP 粘包规则。
- 视频上传需明确最后一包长度、续传能力、文件校验值和取消命令。
