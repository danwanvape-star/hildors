# P20 upload socket trace — 0.1.65+66

Upload result page offers localized Copy device communication log. It copies a bounded, in-memory trace to the clipboard only after an explicit tap. No automatic network upload or persistent log file.

RX records actual socket chunks before frame decoding, including framing, CRC and malformed data. TX records the upload request; raw media writes record byte count only. Each line has UTC timestamp and direction. Only upload phases are traced, so other commands such as network configuration are excluded. Protocol filenames appear in the upload request. Recent history is capped at about 64K characters; individual RX/TX metadata chunks above 4096 bytes are explicitly marked truncated. Audio and video uploads share the log across transport closure, enabling first-ACK investigation.

This is application socket logging, not PCAP: socket chunks are not physical TCP packet boundaries; TCP headers, packet sequence numbers and retransmissions are not captured. TX enqueue is not proof of remote receipt. True PCAP requires a separate network/device capture setup.

Validation: 16 tests passed across bounded raw log and transport suites. Hardware capture remains to be collected by the user. No backend deployment or data migration. Existing UI and protocol behavior retained. Rollback via targeted revert and higher Android build number.
