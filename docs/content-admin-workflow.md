# 内容管理与创作者投稿改造

实施目录：独立工作区 hildors-content-admin（分支 codex/content-admin-workflow）。

## 已确认的产品规则

- 内容列表每页 20 条，小封面展示；按名称、创作者、出品方、形式、题材和审核状态查找。
- 后台新建内容由服务端固定为 HILDORS 出品；创作者投稿绑定当前认证身份。
- 首次初始化预置 10 个题材标签。运营可以添加、改名、停用；已有内容的历史标签保留。
- 新内容必须填写角色背景介绍，单视频和角色视频包均适用。既有内容允许补充介绍。
- 创作者草稿 → 提交审核 → 通过入库／退回修改。通过不会自动上架，需运营单独发布。
- 创作者只能访问自己的投稿；待审核或已通过的投稿不能直接改动素材或介绍。
- 审核记录和内部归属不出现在公开目录。公开署名尊重匿名标记。

## 接口与存储

复用现有 SQLite packages JSON 文档，新增 description、ownerId、creator、submissionStatus 字段；无删除数据迁移。content_tags 表保存标签 id/name/active，首次建表才预置标签，不会在重启时重新启用运营停用的标签。

- GET /v1/content-tags：上传双方共用标签库。
- GET/POST /admin/content-tags：运营管理题材。
- POST /admin/packages：创建官方草稿。
- POST /admin/packages/:id/metadata：版本校验后编辑名称、标签和故事。
- GET/POST /v1/me/content：我的投稿列表／创建草稿。
- GET /v1/me/content/:id：投稿详情。
- POST /v1/me/content/:id/metadata、/submit：编辑、提交审核。
- PUT /v1/me/content/:id/cover、/clips/:clipId/media：上传封面／MP4，带 If-Match 版本。
- POST /v1/me/content/:id/clips/:clipId/inspect：检查视频，带 JSON version。
- POST /admin/packages/:id/review：人工审核，通过须填写授权核对记录。
- POST /admin/packages/:id/publish：单独上架。

上传沿用既有大小、格式和视频解码限制；此改造不新增厂家转码能力。

## 视频包按实际上传管理

此调整取代此前的视频数量输入方案。后台新建角色视频包只填写角色信息，clips 为空；详情中可多选 MP4 及后续追加。视频名称取自文件名，上传成功才新增记录并计入总数，失败不产生空条目；旧草稿中的未上传位置不计数。

已上架包追加的视频先保持私有，检查及单条授权审核通过后才上架，已有视频不受影响。每条视频可单独下架或重新审核上架；草稿内下架条目可恢复至草稿。后台显示上传总数和已上架数，用户端只收到上架条目；最后一条下架后角色包暂不出现在公开目录。服务器同时拒绝已下架视频的原播放、缩略图和权益下载请求。

新增 PUT /admin/packages/:id/clips（原始 MP4、filename 参数、If-Match 版本）与 POST /admin/packages/:id/clips/:clipId/publish、withdraw、restore。追加素材限官方包；创作者原有提交审核约束不变，运营可对已上架创作者包执行单条下架或复审恢复。单个包沿用 100 条、每条 256 MiB 限制。已下载或此前缓存到设备的数据不能由服务器追溯撤回。

## 运营创建、自动缩略图与审核简化

本节取代此前要求运营手填审核说明和授权材料编号的操作。后台新建内容至少选一项题材，创建后立即打开详情，继续上传主图和视频。内容编号由服务端以 `HD-` 加稳定内容 ID 生成，旧内容亦可显示；审核记录 ID 自动生成，操作结果、时间与操作人保留，不把内容编号冒充授权材料。

运营页面上传、追加或替换视频使用 `process=auto`，服务器串行完成检查和缩略图后返回结果。正常完成时不再显示手工检查按钮；失败则保留已上传素材并允许重试，失败素材不能通过审核。旧 API 默认行为保持兼容。旧空视频占位在追加实际文件时移除，不占上传容量，也不阻止角色包审核。

审核通过只需选择通过并保存；单条新增视频同样无需手填说明或编号。退回仍必须说明原因。审核不替代内容使用权判断，也不会自动向创作者作品授予权限。通过入库与最终上架继续分开。

验证：67 项后端测试全部通过，含四个真实 MP4 上传后自动生成缩略图、自动处理串行化、失败后重试、100 个旧空位置兼容、处理期间下架状态保留、无标签拦截。浏览器实测创建直达详情、自动缩略图和无手填审核表单。
