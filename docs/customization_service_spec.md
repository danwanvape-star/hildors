# Hildors 定制服务业务闭环（V1）

## 1. 核心产品决策

定制服务与设备控制解耦：用户可先购买、制作并下载内容，连接 P20 后再传入设备；设备离线不影响订单履约。

- **支持对象**：人物、宠物、商品三类分开提交，不允许一个订单混合多个主体。
- **开放顺序**：人物和宠物正式开放；商品仅向通过资质审核的商用客户开放，待商标和广告合规流程稳定后全面开放。
- **售卖方式**：单次定制为基础；订阅采用“持续角色服务 + 每月额度”；固定主题内容包作为加购，不单独替代订阅。
- **内容权利**：已验收交付的成品可在取消订阅后继续使用；未消耗额度、持续更新、云端同步和订阅专属素材随订阅结束而失效。
- **交付入口**：成品先进入 App“我的素材库”，用户可下载到手机，再通过局域网传入 P20。

## 2. 服务商品定义

### 2.1 单次定制

一次订单对应一个主体、一个基础形象和约定数量的动作视频。默认包含：

- 1 个主体形象和 1 个基础造型或视觉风格；
- 商品页约定的动作数量、分辨率、时长和交付格式；
- 1 次集中修改机会，仅限已提交需求范围内的修正；
- 永久个人设备播放许可；商用用途须购买商用许可。

新增主体、改变风格方向、增加动作或改变用途视为增购，不属于免费修改。

### 2.2 订阅

订阅的核心商品是一个可持续维护的“专属角色档案”，不是单纯素材包。

- 每个订阅绑定一个人物或宠物角色；更换主体需新建角色或购买迁移服务。
- 每个计费月发放内容额度，用于生成约定数量的动作或短视频。
- 当月额度有效期、是否结转及上限必须在购买页明确；V1 建议最多结转 1 个自然月。
- 节日、场景、动作主题包可用额度兑换或额外购买。
- 已生成并完成验收的内容不因订阅取消而失效。
- 暂停或取消后，不再发放额度，不再享受持续更新、订阅折扣及云端角色维护。

## 3. 用户提交与需求字段

### 3.1 通用必填字段

| 字段 | 规则 |
|---|---|
| 定制类型 | 人物 / 宠物 / 商品，单选 |
| 主体名称 | 用于角色和素材库识别，不直接写入公开视频 |
| 主要用途 | 个人陪伴 / 家庭娱乐 / 礼物 / 展示 / 商业宣传 |
| 风格 | 写实 / 卡通 / 科幻 / 其他受支持模板 |
| 动作或情节 | 从标准动作库选择，并允许补充文字说明 |
| 画面要求 | 方向、背景、是否循环、是否需要声音 |
| 设备型号 | P20 / P11 / 暂无设备，用于确定输出规格 |
| 交付说明 | 期望日期及备注；日期不是承诺，以下单页确认工期为准 |
| 权利声明 | 用户确认拥有照片、肖像、商标及相关内容的合法使用权 |
| 隐私授权 | 单独勾选制作处理授权、保存期限和可选的案例展示授权 |

### 3.2 素材要求

- 上传 3–8 张清晰原图，至少包含正面、左右侧面和全身或主体全貌；不得仅上传聊天截图或严重压缩图。
- 人物需补充年龄段；未成年人必须由监护人提交并确认授权。
- 宠物需补充品种、毛色、明显特征及希望保留的识别点。
- 商品需补充品牌归属、商标授权、标准色、不可改动元素及商用范围。
- 上传页实时提示清晰度、遮挡、主体数量和文件格式，但机器检测结果不等同于审核通过。

## 4. 审核、授权与隐私规则

### 4.1 审核规则

订单进入制作前必须经过自动检测和人工审核：

- 拒绝违法、色情、仇恨、暴力极端、欺诈或明显侵权内容；
- 拒绝无授权的公众人物、第三方人物、品牌、影视动漫角色和商标仿制；
- 拒绝将未成年人制作成不当、危险或商业代言内容；
- 拒绝质量不足、主体不一致或无法达到交付标准的素材；
- 疑似侵权或授权不完整时，订单进入“待补充材料”，不得进入制作。

审核拒绝时给出类别化原因。未进入制作的订单原路全额退款；涉嫌恶意或违法提交时可限制账户再次提交。

### 4.2 授权拆分

以下授权必须分别展示，不得合并为一个默认勾选框：

1. **履约必需授权**：允许在订单履约范围内处理上传照片和需求；不同意则无法下单。
2. **云端保存授权**：允许在交付后保存源素材和角色工程，便于返修和持续订阅；用户可申请提前删除。
3. **案例展示授权**：允许用于官网、社交媒体或展会展示；默认关闭，可随时撤回未来使用。
4. **AI 改进授权**：如未来需要用于模型训练或改进，必须另行、明确、可撤回地征得同意；默认关闭，不能作为购买条件。

### 4.3 数据生命周期

- 原始素材仅向履约所需人员开放，全程记录访问和导出日志。
- 非订阅订单建议在验收后 30 天删除原始上传文件和中间工程；成品按用户素材库规则保存。
- 有效订阅的角色工程在订阅期内保存；订阅结束后保留 30 天恢复窗口，随后删除源素材和工程。
- 用户注销或提出删除请求时，删除非法律留存所必需的数据；订单、支付等法定留存数据与创作素材分开保存。
- 隐私政策须明确第三方存储、生成服务、支付服务的处理范围和所在地区。

## 5. 订单、支付、制作与交付

### 5.1 主流程

1. 用户选择服务和主体类型。
2. 填写需求、上传素材并完成授权。
3. 系统生成报价和预计工期。
4. 用户确认订单并全额支付；未支付订单不进入人工审核。
5. 自动检测和人工审核。
6. 审核通过后订单进入制作，工期开始计算；需补充资料时工期暂停。
7. 制作方提交带水印预览。
8. 用户在 7 天内一次性提交修改意见或确认；逾期提醒后按订单约定自动验收。
9. 修改完成并确认后生成最终设备包。
10. 成品进入“我的素材库”，订单标记已交付。

### 5.2 订单状态

`草稿 → 待支付 → 审核中 → 待补充资料 / 已拒绝 → 制作中 → 待验收 → 修改中 → 打包中 → 已交付`

终止状态包括：`已取消`、`已退款`、`售后关闭`。任何状态变化均记录时间、操作者和原因，并通过 App 消息通知用户。

### 5.3 退款与变更

- 审核前用户可取消并全额退款。
- 因平台审核拒绝或平台无法制作，全额退款。
- 进入制作后，因数字定制品已产生人工成本，不支持无理由全额退款；按商品页预先公示的制作阶段结算。
- 成品与已确认需求明显不符时，平台应免费修正；仍无法达到约定标准时进入人工售后，可部分或全额退款。
- 支付后新增主体、动作或改变风格方向须生成补差价单，用户确认后继续制作。

## 6. 视频包交付与设备传输

### 6.1 视频包结构

每次交付生成一个带版本号的设备包，至少包含成品视频、封面图，以及记录包 ID、角色 ID、版本、目标设备型号、文件哈希、大小、时长、编码规格和授权类型的 `manifest`。

### 6.2 下载到手机

- “我的素材库”展示待下载、下载中、已下载、更新可用和下载失败状态。
- 支持续传、失败重试和本地空间检查；完成后校验哈希，再允许传入设备。
- 用户可删除手机缓存；删除缓存不等于删除云端成品或设备内副本。

### 6.3 传入 P20

1. 用户在素材详情点击“传入设备”。
2. App 检查 P20 连接状态、型号兼容性、电量及剩余空间。
3. 不兼容时禁止传输并提示重新转码或选择对应版本。
4. App 经局域网分包上传，展示准备、传输、校验、完成或失败状态。
5. P20 返回文件校验和最终保存结果后，App 才显示“已传入设备”。
6. 中断后根据设备协议续传；设备不支持续传时明确提示将重新上传。

云端下载和局域网传输是两个独立任务：手机暂时无法联网时，已下载素材仍可传入 P20；连接 P20 热点导致互联网断开时，不得让云端下载任务误报完成。

## 7. 取消订阅后的权益

| 内容或能力 | 取消后规则 |
|---|---|
| 已验收交付的视频 | 可永久在本人账户和已授权设备上使用 |
| 已下载到手机或 P20 的成品 | 不远程删除，可继续播放 |
| 云端成品下载 | 订阅结束后至少保留 90 天下载窗口；长期保存策略须在购买页明确 |
| 未使用月度额度 | 订阅期结束时失效，不折现、不转让 |
| 已提交且已扣额度的制作任务 | 继续履约至交付，不因取消中止 |
| 角色源素材和中间工程 | 保留 30 天恢复窗口，随后删除 |
| 新动作、节日更新和订阅折扣 | 订阅期结束后停止 |
| 已购独立内容包 | 按购买时许可继续使用 |

“永久使用”指已交付文件的使用许可，不承诺永久云存储、永久兼容未来设备或持续提供转码服务。涉及商用时，以订单中的商用许可范围为准。

## 8. 后台与运营最小能力

- 订单队列、审核工作台、补件、分配制作人和工期预警；
- 需求版本、用户确认记录、修改次数和交付版本管理；
- 支付、退款、补差价、发票及对账；
- 素材访问权限、下载水印、操作日志和删除任务；
- 角色档案、订阅额度账本、到期与取消处理；
- 视频包转码、兼容性校验、发布、撤回和重新交付；
- 客诉、侵权投诉、紧急下架与设备端内容处置指引。

## 9. V1 验收标准

- 用户能在下单前看见价格、交付物、预计工期、修改次数、退款条件和使用许可。
- 未完成履约授权、权利声明或必要素材上传时不能支付。
- 审核、补件、制作、验收、交付和退款均有可追踪状态。
- 成品必须先进入素材库，经过完整性校验后才能传入兼容设备。
- App 只有收到 P20 成功应答后才显示“已传入设备”。
- 订阅额度的发放、扣减、退回、过期均进入不可篡改的额度流水。
- 取消订阅前明确提示停止的权益、仍保留的内容和数据删除日期。

## 10. 上线前必须配置的商业参数

各套餐价格、每月额度、额度结转上限、标准动作数、制作工期、预览验收期限、制作阶段退款比例、云端成品保存期、支持的视频规格、不同设备型号的包格式及商用许可价格，均应由后台配置，不写死在 App 中。
