# Hildors 多 AI 工具编排与生产架构（V1）

## 1. 架构目标

系统需要同时支持 GPT、Grok、图像生成、视频生成、抠像、补帧、转码和内容审核工具，但订单系统不直接依赖任何具体供应商。

目标：

- 更换工具不改变用户订单、价格、权益和状态；
- 用户照片只发送给当前任务必要且已批准的工具；
- 每个任务可限制尝试次数、预算和总时长；
- AI 失败后可以安全切换工具或转人工；
- 所有输入、输出、成本、版本和人工操作可追溯；
- 未通过审核或质检的产物不能进入用户素材库。

## 2. 总体结构

```text
App / 运营后台
      ↓
订单与角色服务
      ↓
生产编排服务 ─────→ 人工任务中心
      ↓
安全与授权网关
      ↓
工具适配层
  ├─ 文本/需求模型适配器
  ├─ 图像生成适配器
  ├─ 视频生成适配器
  ├─ 后期处理适配器
  └─ 内容审核适配器
      ↓
已批准的外部 AI 服务

产物统一进入隔离存储 → 自动技术检查 → 人工质检 → 发布存储
```

订单服务是业务事实来源；编排服务只执行生产任务，不能自行改变价格、授权或用户验收结果。

## 3. 服务边界

### 3.1 订单与角色服务

负责：

- 订单、需求版本、角色基准和用户确认；
- 权利声明、隐私授权和许可范围；
- 支付、点数、补价和退款；
- 用户可见状态及通知。

不负责直接调用模型。

### 3.2 生产编排服务

负责：

- 把已批准订单拆成分析、基准图、视频、修复、质检和转码任务；
- 根据风险、能力、成本和可用性选择工作流；
- 管理依赖、重试、预算、超时、取消和人工接管；
- 汇总供应商结果，但不自动发布成品。

### 3.3 安全与授权网关

任何外部工具调用前必须经过网关检查：

- 订单是否已支付并通过审核；
- 当前授权是否覆盖主体、用途和处理方；
- 工具是否允许处理当前风险等级和数据类型；
- 输入文件是否仍在保存期限内；
- 是否达到订单、用户或供应商预算上限；
- 是否包含任务不需要的个人信息；
- 是否命中暂停、删除或紧急阻断标记。

检查失败时返回明确原因码，不允许制作人员绕过网关手动上传。

### 3.4 工具适配层

每类工具实现统一接口，把供应商参数和状态转换为内部格式。业务流程不得直接读取供应商原始状态。

## 4. 统一任务模型

```text
ProductionTask
  id
  order_id
  character_id
  requirement_version_id
  task_type
  risk_level
  workflow_id / workflow_version
  status
  priority
  input_asset_ids
  output_asset_ids
  provider_id / model_id / model_version
  attempt / max_attempts
  budget_limit / actual_cost
  timeout_at
  assigned_operator_id
  idempotency_key
  parent_task_id
  failure_code
  created_at / started_at / completed_at
```

任务状态：

`created → policy_check → queued → running → validating → completed`

异常分支：

- `waiting_human`：等待人工处理；
- `retry_scheduled`：等待有限重试；
- `blocked`：授权、风险或工具策略阻断；
- `failed`：达到重试或预算上限；
- `cancelled`：订单取消、退款或人工终止。

## 5. 工具注册表

```text
ProviderCapability
  provider_id
  capability_type
  allowed_subject_types
  allowed_risk_levels
  allows_minor_data
  allows_voice_data
  allows_commercial_output
  training_opt_out_confirmed
  retention_policy
  deletion_supported
  data_regions
  max_file_size
  supported_formats
  average_latency
  cost_formula
  daily_budget
  status
  approved_at / review_at
```

工具状态：

- `evaluation`：只能使用合成测试素材；
- `low_risk_only`：只允许 L1；
- `scenario_limited`：只允许明确批准的主体或用途；
- `approved`：在注册能力范围内可用；
- `degraded`：停止新任务，只完成或迁移在途任务；
- `suspended`：立即停止调用；
- `disabled`：不可选择。

供应商条款、数据策略或模型版本重大变化时自动转为待复审，不应默认继承旧批准。

## 6. 工作流定义

工作流使用版本化模板，不将步骤硬编码在客户端：

```text
Workflow
  id: pet_standard_video
  version: 3
  allowed_risk_levels: [L1, L2]
  steps:
    - source_quality_check
    - subject_feature_extract
    - baseline_generate
    - baseline_validate
    - user_baseline_approval        // L2 必需
    - storyboard_generate
    - video_generate
    - artifact_detect
    - human_quality_review
    - device_transcode
    - package_validate
```

每个步骤定义：输入类型、输出类型、候选工具、超时、最大尝试、预算、校验器、失败策略和是否必须人工批准。

工作流新版本只作用于新任务；在途订单默认继续使用创建时锁定的版本，除非迁移经过人工批准并留痕。

## 7. 路由策略

### 7.1 硬性过滤

先排除：

- 未批准或暂停的工具；
- 不支持当前人物、宠物、商品或声音类型的工具；
- 不允许当前风险等级、商用范围或未成年人数据的工具；
- 数据区域、保留和训练规则不符合授权的工具；
- 文件规格、输出格式或设备需求不匹配的工具。

### 7.2 评分选择

对剩余工具按任务评分：

```text
总分 = 质量历史 × 40%
     + 主体一致性 × 20%
     + 成功率 × 15%
     + 延迟表现 × 10%
     + 成本表现 × 10%
     + 当前可用性 × 5%
```

权重按任务类型配置。例如人物角色基准提高一致性权重，标准宠物动作可以提高成本和延迟权重。

不得为了低价选择未达到最低质量线的工具。路由结果记录候选集合、最终选择和规则版本。

## 8. 重试与失败切换

### 8.1 可重试错误

- 临时网络错误；
- 供应商限流；
- 明确的临时服务不可用；
- 回调丢失但可查询任务；
- 文件传输校验失败且源文件完整。

同一供应商自动重试最多 1 次，并采用退避。生成内容质量不合格不属于网络重试。

### 8.2 质量失败

- 第 1 次不合格：允许按缺陷原因调整参数或提示后再次生成；
- 第 2 次不合格：停止自动生成，进入 `waiting_human`；
- 人工选择切换工具、局部修复、完全重做或调整可交付方案；
- 不允许系统跨多个付费工具无限试错。

### 8.3 工具切换

切换前重新执行授权和能力检查。新工具不得获得上一工具生成的中间产物，除非该中间产物是任务必需、授权允许且来源许可允许。

切换不改变用户订单价格或修改次数；如原方案确实无法实现，需要通过售后与用户确认调整，不能静默降级。

## 9. 素材最小化与脱敏

- 需求分析模型优先接收结构化字段，不接收原始人物照片；
- 不需要身份的步骤使用裁剪、降采样、遮挡元数据或内部特征引用；
- 提示词使用角色 ID，不写入用户姓名、电话、地址和订单备注中的无关信息；
- 删除图片中的 EXIF、GPS 和设备信息后再发送外部工具；
- 身份证明只用于授权审核，禁止进入生成工具；
- 输入和输出使用短期签名地址，供应商拉取完成后尽快失效；
- 外部工具返回内容先进入隔离存储，不直接进入用户可访问地址。

## 10. Prompt 与参数管理

提示词模板属于版本化生产配置：

```text
PromptTemplate
  id
  task_type
  version
  template
  allowed_variables
  prohibited_variables
  compatible_models
  owner
  test_set_version
  approval_status
```

- 模板变量采用白名单；禁止把完整订单对象直接拼接进提示词；
- 系统提示、用户需求和素材描述分层保存；
- 模板上线前使用无真实个人信息的基准集测试；
- 修改模板必须生成新版本，记录审批和效果对比；
- 提示词日志限制访问，并按比源照片更短或相同的期限保存；
- 外部模型产生的建议、人物描述和事实推断仅作为候选，不写回用户档案成为事实。

## 11. 自动校验器

AI 产物进入人工质检前先执行确定性检查：

- 文件存在、可解码、时长和帧数有效；
- 分辨率、方向、编码、帧率、码率和音轨符合工作流要求；
- 黑底、透明背景、安全区和循环要求符合设备模板；
- 哈希、文件大小和病毒扫描通过；
- 视频不存在全黑、冻结、损坏帧或超长静音；
- 输出数量与任务要求一致；
- 内容安全检测无阻断结果。

身份一致性、审美、动作自然度和复杂侵权风险不能只靠自动分数决定，仍进入相应人工质检。

## 12. 人工任务中心

人工任务必须结构化，不能只通过聊天群分派。

任务卡显示：

- 订单号、风险等级和剩余工期；
- 当前生效需求版本；
- 必要输入和上一轮缺陷；
- 当前产物及角色基准对比；
- 已使用工具、尝试次数、成本和失败原因；
- 允许的下一步操作。

人工操作：

- 修正参数并重试；
- 选择另一个已批准工具；
- 下载到批准的人工软件处理；
- 标记需补件或需求不可实现；
- 提交质检；
- 升级审核或隐私事件。

下载原始素材必须单独授权、记录原因并生成审计日志。完成后不能把工作文件留在个人电脑或聊天工具。

## 13. 发布隔离

存储分为三个区域：

1. **源素材区**：用户上传，仅授权审核和必要制作访问；
2. **生产隔离区**：模型输出、中间工程、失败和待质检产物；
3. **发布区**：通过质检和用户验收的预览或最终文件。

只有发布服务可以把文件从隔离区复制到发布区。制作员上传完成不等于发布成功。

最终发布要求：

- 当前需求版本一致；
- 权利和安全审核有效；
- 内部质检通过；
- 用户验收满足规则；
- 设备包校验通过；
- 文件哈希、许可和保存期限写入清单。

## 14. 成本控制

### 14.1 预算层级

- 单次任务预算；
- 单订单预算；
- 单用户每日异常预算；
- 单供应商每日/月度预算；
- 单工作流平均成本预警。

达到软上限时通知制作负责人；达到硬上限时停止自动调用并转人工。不得因为预算耗尽把未质检结果直接交付。

### 14.2 成本事件

每次调用记录预估成本、实际成本、币种、计费单位、供应商账单 ID 和订单归属。异步任务最终成本与预估不一致时生成调整事件，不覆盖历史值。

### 14.3 成本指标

- 每个合格交付物的平均调用成本；
- 首次通过成本；
- 因质量失败浪费的成本；
- 每种工具和工作流的成功率；
- 人工介入前后的总成本；
- 单订单成本占收入比例。

## 15. 可观测与告警

使用统一追踪 ID 关联订单、生产任务、外部调用、人工任务、质检和发布。

必须告警：

- 未授权素材调用外部工具；
- 暂停工具仍收到新任务；
- 单订单超过预算或尝试次数；
- 外部调用成功但产物未入库；
- 隔离区文件绕过质检进入发布区；
- 工具错误率、延迟或成本异常上升；
- 删除到期素材仍被工作流引用；
- 日志或回调中出现访问令牌、原始照片地址或敏感身份信息。

## 16. 供应商故障与退出

每个工具必须有退出方案：

- 停止新任务；
- 查询并处理在途任务；
- 撤销密钥和回调地址；
- 按约定申请删除供应商侧数据；
- 导出必要的账单和审计证据；
- 将工作流路由至替代工具或人工；
- 重新验证替代工具的质量，不直接假设等价。

发生疑似数据泄露时立即暂停相关工具，冻结可能受影响的素材流转，保留审计证据并启动公司隐私事件响应流程。

## 17. V1 实现建议

V1 不需要建设复杂的全自动智能代理。建议采用可控的任务队列：

1. 订单系统创建生产任务；
2. 编排器按固定版本工作流推进；
3. 制作员在后台选择已批准工具并确认调用；
4. 供应商通过轮询或签名回调返回结果；
5. 自动技术校验；
6. 人工质检；
7. 用户确认；
8. 发布设备包。

先实现“人工确认后调用”的半自动编排，积累各工具真实质量、成本和失败数据后，再逐步允许 L1 标准订单自动路由。

## 18. 技术验收用例

- [ ] 替换某个工具适配器后，订单 API 和 App 无需修改；
- [ ] 未授权人物订单被安全网关阻断且不产生外部调用；
- [ ] 暂停某供应商后，新任务不会进入该供应商；
- [ ] 相同幂等键不会创建两次付费调用；
- [ ] 网络错误只重试一次，质量失败不会被当作网络错误无限重试；
- [ ] 第二次质量失败后自动创建人工任务；
- [ ] 达到硬预算上限后停止调用并保留当前任务状态；
- [ ] 供应商重复回调不会重复产生成本或产物；
- [ ] 外部返回文件先进入隔离区，不能通过公开地址访问；
- [ ] 未通过质检的产物无法进入发布区；
- [ ] 已到删除期限的源素材不能被新任务引用；
- [ ] 日志中不出现长期有效下载地址、密钥或完整身份资料；
- [ ] 每个最终文件可以追溯到需求、授权、输入、工具、人工修改、质检和用户验收；
- [ ] 工具退出演练可以停止新调用、处理在途任务并切换替代方案。
