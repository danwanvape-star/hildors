## 统一约束与文档冲突处理

- 当前用户要求优先：不增加定制视频下载、导出或分享原文件功能；定制内容仅能通过受控方式传入绑定设备。
- 旧照片定制文档里的“下载手机”“成品下载期限”等不作为当前产品需求。未来若实现传输所需私有缓存，也不能据此增加用户可访问的文件下载入口。
- 免费领取、免费预审、付费制作和第三方 IP 许愿保持清晰区分；未经适用授权的第三方角色不进入付费定制。
- 保留现有业务规则、仓储接口和自动化测试。未接入的支付、云端权益、真实受控播放与设备安装服务，应继续明确显示实际接入状态。
- 人工勾选质检不等于自动媒体检测或真机采集；本地原型的传输记录不等于真实设备回执，更不能据此宣称已完成固件级安全交付。
- 本任务不接管发现页、社交、全息宠物或其他无关模块；共享导航、主题和依赖变更需统一协调。
