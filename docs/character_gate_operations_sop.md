# 角色之门：制作运营与质量控制SOP（V1）

## 1. 适用工单

- `LICENSED_INSTANT`：正版预制角色包，即时交付；
- `LICENSED_CUSTOM`：正版角色许可范围内的制作型个性化；
- `OC_LITE`：素材完整的原创角色建角；
- `OC_STANDARD`：需要补全和较多人工修复的原创角色；
- `FIGURE_DISPLAY`：原创手办数字陈列；
- `FIGURE_ACTIVE`：原创手办角色活化；
- `ACTION_CUSTOM`：已有角色的自定义动作；
- `IP_WISH`：未签约IP许愿，不是付费订单。

不同工单不得共用同一报价、交付时间和审核强度。

## 2. 岗位与责任

| 岗位 | 主要责任 | 不得擅自决定 |
|---|---|---|
| 订单协调 | 完整性检查、补件、进度和用户沟通 | 法律结论、未确认的交期和效果 |
| 权利审核 | 角色、手办、模型、音乐、动作参考和用途 | 在证据不足时默认放行 |
| 制作师 | 角色基准、生成、合成、修复和设备适配 | 使用未批准的个人工具处理素材 |
| 质量审核 | 基准一致性、动作、画面、声音和循环 | 只凭制作师自检放行 |
| 设备测试 | P20/P11传输、索引、播放和恢复 | 用模拟画面代替真机检查 |
| 运营负责人 | 产能、升级、退款、工具与质量指标 | 跳过权利或安全审核做加急 |

P0阶段可以一人兼任多个岗位，但最终真机放行不能只由原制作人完成。

## 3. 工单状态机

```text
draft
→ submitted
→ automated_precheck
→ rights_review
→ quote_required / ready_for_payment
→ payment_pending
→ paid
→ material_review
→ baseline_in_production
→ baseline_user_review
→ action_in_production
→ human_repair
→ device_qa
→ delivery_user_review
→ approved
→ installing
→ delivered
```

异常状态：

```text
more_information_required
rights_escalation
changes_required
user_change_requested
requote_required
paused_by_user
paused_by_operations
refund_in_review
cancelled
rejected
recalled
```

每次状态变化记录时间、操作者、原因、下一责任人和预计更新时间。

## 4. 权利预审

- `R0`：平台已授权角色，使用范围已配置；
- `R1`：用户原创且证据充分；
- `R2`：公版来源再设计，需要排除现代受保护版本元素；
- `R3`：第三方元素或证据不完整，暂停并补件；
- `R4`：明确未授权、冒充或禁止内容，拒绝；
- `R5`：高价值IP、商业用途或法律不确定，升级审核。

只有`R0–R2`可以进入正常付款。`R3/R5`在结论前不得收取不可退制作费。

自动识别只能分流，不能将“未检测到问题”表述为版权审核通过。

## 5. 标准制作流程

### 5.1 自动预检

检查文件损坏、分辨率、角度、多主体、遮挡、疑似真人、第三方IP、商标、水印、音视频参考、设备和用途。

### 5.2 人工素材审核

确认目标角色唯一、参考图一致、关键细节可见、锁定细节合理、输出适合设备。补件要求一次集中发送，避免逐项往返。

### 5.3 报价

报价必须包含交付物、不包含内容、完成日期、确认节点、修改次数、用途许可、变更费用和分阶段退款规则。报价有效期建议7天。

### 5.4 角色基准

建立正面、侧面、背面、比例、面部、发型、颜色、材质、服装、配件和最多5项锁定细节。制作师自检后由另一人审核，再发给用户确认。

用户可以：

- `确认形象`：进入动作制作；
- `报告与参考不一致`：免费质量修复；
- `提出新的形象需求`：重新报价。

### 5.5 动作制作

动作任务必须写明目的、起止姿态、时长、循环点、镜头、音乐、节拍、道具、特效、安全区和禁止事项。

同一缺陷连续两轮未能修复，必须更换制作路径或升级高级制作师，不继续无限尝试同一工具。

### 5.6 人工修复

重点处理人脸、手指、服装漂移、武器/翅膀/尾巴断裂、闪烁、跨帧不一致、穿模、透明边缘、循环断点和音画不同步。

### 5.7 真机质检

在目标设备和固件上检查：

- 下载、哈希、传输和索引；
- 首帧、末帧和循环；
- 黑场融合与普通光线可见性；
- 多角度观看和安全区；
- 动作拖影；
- 音量和同步；
- 离线播放；
- 删除、重装和断点恢复。

保存真机验收证据并标注设备、固件和日期。

### 5.8 用户验收与安装

用户反馈先分类为质量问题或需求变更。质量问题免费修复；需求变更重新报价。验收后完成设备安装、首次见面动作、角色护照和安装记录。

安装失败不改变内容制作已完成的事实，但必须进入技术售后，并保留重新下载和恢复能力。

## 6. 服务时限建议

时限从“素材和权利完整”开始计算：

| 环节 | 运营目标 |
|---|---:|
| 自动检查 | 5分钟内 |
| 标准权利预审 | 1个工作日 |
| 标准报价 | 1个工作日 |
| OC Lite角色基准 | 3–5个工作日 |
| OC Standard角色基准 | 5–8个工作日 |
| 模板动作追加 | 2–4个工作日 |
| 自定义动作 | 5–12个工作日或按报价 |
| 真机质检 | 1个工作日 |
| 用户质量反馈响应 | 1个工作日 |

订单页应显示具体预计日期和延期更新方式，而不是将内部目标作为无条件承诺。

## 7. 缺陷等级

- `S0` 安全、违法或严重权利问题：立即暂停并升级；
- `S1` 无法播放、角色错误、主要画面损坏或交付缺失：阻止交付，优先修复或退款；
- `S2` 明显闪烁、穿模、循环跳变、同步偏差或重要细节不一致：交付前修复；
- `S3` 不影响主体的轻微瑕疵：按真机可见程度处理。

不能用S3分类掩盖用户在设备上可以清楚看到的问题。

## 8. 交付检查表

### 角色

- [ ] 面部、发型、比例、颜色和材质符合基准；
- [ ] 锁定细节全部保留；
- [ ] 武器、配件、翅膀和尾巴结构完整；
- [ ] 正版角色符合品牌规范。

### 画面与动作

- [ ] 无明显多肢、断肢、穿模或跨帧变形；
- [ ] 主体未超出设备安全区；
- [ ] 循环自然且没有危险频闪；
- [ ] 黑底、透明和边缘处理合格；
- [ ] 音画同步且音量不过载。

### 权利与设备

- [ ] 角色、音乐、声音和动作来源已记录；
- [ ] 无未经批准的声音克隆；
- [ ] 设备包、哈希、安装、索引和离线播放通过；
- [ ] 删除、重装和恢复通过。

## 9. 退款与变更

不使用“定制内容概不退款”。按阶段和实际已完成工作处理：

| 阶段 | 原则 |
|---|---|
| 未付款 | 可取消 |
| 已付款但人工工作未开始 | 原路退款，扣费须有明确合法依据 |
| 权利/素材审核未通过 | 未发生部分退回；平台原因不由用户承担 |
| 角色基准制作中 | 按事先披露且实际完成的工作结算 |
| 角色基准已确认 | 建角部分视为完成，未开始动作部分可退 |
| 动作制作中 | 按可用交付物和已完成阶段处理 |
| 交付存在质量问题 | 优先修复、替换、降价或按适用规则退款 |
| 用户改变需求 | 原规格继续，或补价变更 |

具体比例需按销售地区消费者规则和支付渠道完成正式法律审核。

## 10. AI工具管理

每个批准工具记录：用途、版本、账号、商用条款、数据保存/训练设置、可处理素材类型、输出权利、供应商地区、替代工具和最近审核日期。

制作师选择GPT、Grok或其他内部工具，用户不选择供应商。工具发生重大条款、数据处理或模型变化时重新审核。

内部成本记录：

```text
ai_generation_cost
rights_review_minutes
human_edit_minutes
device_qa_minutes
revision_minutes
customer_support_minutes
refund_and_payment_cost
```

订单毛利必须计入人工和失败成本，不能只看AI调用费用。

## 11. 产能与队列

分开管理权利预审、补件、角色基准、动作制作、人工修复、设备质检、用户验收和技术售后队列。

优先级：

1. S0/S1；
2. 临近承诺日期的已付款订单；
3. 用户补件或确认后恢复的工单；
4. 标准订单；
5. 未付款预审；
6. IP许愿归并。

首发按周限制新建角名额，根据真实人工分钟扩大，不通过隐瞒等待时间吸收超卖。

## 12. 首轮运营演练

正式付费前完成10类模拟工单：

1. 正版角色即时购买和安装；
2. 正版角色个性欢迎动作；
3. 完整三视图OC；
4. 单图且需要背面补全的OC；
5. 原创手办数字陈列；
6. 疑似第三方IP手办；
7. 含未授权流行音乐的动作请求；
8. 基准确认后更换服装；
9. 安装中断并恢复；
10. 交付后发现明显穿模并修复或退款。

每类记录实际周期、AI成本、人工分钟、失败点、用户文案、返修次数和毛利，再决定首发价格与每日名额。

## 13. P0团队建议

- 1名订单/客服协调；
- 1名权利与内容审核负责人，可兼职；
- 2名角色和视频制作师；
- 1名质量与设备测试人员；
- 1名产品/运营负责人。

每日关注待处理量、超时、等待用户、S0/S1、设备失败、退款和投诉；每周复盘通过率、周期、人工分钟、返修、真机一次通过率、毛利和首次唤醒完成率。
