# 单／双列表兼容验证记录

日期：2026-09-28。业务基线：`98af6be48102f193a29d13c88d55d265adca382f`，版本 `0.1.66+67`。实现分支：`codex/single-dual-device`。本次未发布新版本、未推送、未制作 APK。

## 软件行为

- 默认顺序探测双列表和单列表，连接验证完成才显示已连接；设置页可以限定设备类型。
- 单列表只有一个视频列表，不显示蓝牙音频控制。视频准备复用原取景与转码组件，不抽取、不生成、不上传音频。
- 双列表 v2 传输实现未修改，保留 32768 分包、列表 ID、厂家固定 ACK 序号的既有行为。
- 单列表验证传输为 35700 字节分包、固定 CRC02、无列表 ID、ASCII `.bin` 文件名不超过32字节。最后不足整包的文件在发送前拒绝，不能猜测填充规则。
- 单列表普通上传默认关闭。只有编译时指定 `--dart-define=HILDORS_SINGLE_UPLOAD_VALIDATION=true` 才允许实验上传，仍执行长度与协议校验。已生成候选视频不等于能在单列表硬件上播放。
- 连接切换会使旧媒体任务与删除确认失效；素材目录缓存按连接代次隔离。

## 自动化与构建

工具链：Flutter 3.47.4 / Dart 3.13.3；Xcode 26.3；模拟器 iPhone 17 Pro，iOS 26.3。

完整命令：

```sh
flutter analyze --no-pub
flutter test --no-pub --reporter compact
flutter build ios --simulator --debug --no-pub \
  --dart-define=HILDORS_RELEASE_PROFILE=us_free \
  --dart-define=HILDORS_API_BASE_URL=https://api.hildors.com
```

静态分析无问题；完整测试598项通过、5项跳过，无失败。iOS 模拟器构建成功，并安装启动，已查看首页。没有连接真实硬件，单列表识别后的页面由 widget/TCP 测试验证，不能据此声称已验证硬件播放。

五项保留的跳过测试：

- `backend_app_download_e2e_test.dart`、`owned_download_e2e_test.dart`：未设置 `HILDORS_APP_E2E=1`。
- `p20_ffmpeg_integration_test.dart`：未设置 `HILDORS_FFMPEG`。
- `p20_audio_vendor_integration_test.dart` 的两项测试：未设置 `HILDORS_FFMPEG`。

独立代码审阅发现的两个重要问题已修复并做失败→通过验证：同一 TCP 数据块里的最终进度与完成回执不能丢失；跨设备切换后，旧删除确认不能删除新设备的同名文件。没有延期的小问题。

完整测试还发现了旧列表测试选择器过期，已按现有 IconButton 和固定控制区／滚动列表结构修正；设备类型选择器新增大字号适配。

GBK 运行时大字典初始化在本工具链中出现类型错误或测试进程崩溃。`third_party/gbk_codec` 保留锁定的0.4.0库，唯一源码补丁是将两个相同映射字典预编译为常量。字节比较确认映射内容和转换算法未变；授权文件和原文件哈希见该目录 PATCH.md。无其他依赖版本升级。

验收顺序：先对双列表用相同素材回归两个列表；再获取厂家已能播放的单列表文件，记录文件 SHA256 和固件版本，核对实际原始回执及末包；最后上传现有编码器产生的短视频检查播放效果。非整包文件必须先确认规则并补充测试，不能通过改后缀或补零绕过。传输和播放均验证后才能开放单列表普通上传。

## 实施决定及限制

1. 原生工作树工具无法操作聊天镜像，改用真实仓库的 Git 工作树；若需要应用管理，需手动关联该目录。
2. 保留显式 legacy 构造方式兼容旧协议测试；正式 App 使用自动验证。显式关闭验证的调用方仍自行承担设备识别责任。
3. 已有双列表验证连接测试保持不变，新单列表测试独立添加，无功能差异。
4. 单列表超时允许注入，产品默认10秒，便于测试；错误缩短该参数会造成提前超时。
5. 文案走现有 ARB 生成流程，连接测试替身补充真实能力描述，未知设备继续禁止上传。
6. 修正原基线已过期的列表测试定位器，保留实际调序与列表切换断言；定位器仍需随界面结构维护。
7. 固定GBK常量映射补丁以避免初始化失败，代价是维护一个现有依赖的本地覆盖；映射及算法未变。
8. 厂家未明确的编码、末包和序号不能由审阅代替实机确认，默认阻止普通单列表上传；代价是已兼容机器也需验证后才能开放。
9. 独立审阅后的布局、测试环境和两处常量映射修补由当前执行者验证，没有再次派出审阅者；证据为完整测试、构建及映射原文对比。
10. 模拟器无法替代硬件连接，单列表页面使用widget/TCP测试；系统权限和实机播放保留为待验收项。
