# 角色之门：专属全息角色体验方案（V1）

## 1. 产品定义

“定制你的专属全息角色”不是一个开放式AI生成器，而是把用户与角色之间的关系转化为可在Hildors设备中持续陪伴、表演和成长的数字收藏体验。

核心承诺：

> 让用户安全地把“我喜欢的角色、我原创的角色或我的实体收藏”带进角色之门，并在付款前看见明确可交付的形象、动作、权利范围和设备效果。

体验关键词：进入、唤醒、塑造、赋予行为、建立羁绊、降临设备。

## 2. 首要原则

1. **先问角色来源，再问用户想生成什么**：来源决定可用能力、审核和商业规则。
2. **正版IP做许可范围内的个性化，不做任意改造**。
3. **原创角色允许深度定制，但需要建立来源和权利证据**。
4. **实体手办所有权不等于角色IP改编权**；平台只把照片作为造型参考，不默认获得数字化许可。
5. **未签约IP进入许愿池，不进入付费制作订单**。
6. **先展示可行性与价格区间，再要求用户填写长表单**。
7. **用户不选择GPT、Grok或内部工具**；平台对最终结果、人工修复和交付负责。
8. **角色不是一次性视频**；每个成功项目都建立一个可继续扩展的“角色护照”。

## 3. 三条入口路径

### A. 正版角色个性化

适用于Hildors已取得授权的游戏、动漫、虚拟偶像和原创合作IP。

用户可以在授权范围内选择：

- 官方服装、主题和配色；
- 昵称和设备内称呼；
- 待机性格倾向；
- 官方动作、歌曲和表演包；
- 欢迎语、纪念日和陪伴事件；
- 角色在设备中的位置、大小和播放组合。

默认不允许：

- 改变角色核心外貌、种族、年龄或品牌识别；
- 色情化、仇恨化或政治化改造；
- 与未授权角色、品牌、音乐或服装联动；
- 克隆原配音演员声音；
- 导出可在其他商业平台使用的角色资产。

这是转化率最高、交付最稳定的路径，应放在入口第一位。

### B. 原创／自有角色定制

适用于用户原创OC、委托创作并取得数字化权利的角色、自有品牌吉祥物，或权利清晰的公版角色再设计。

允许提交：

- 正侧背角色设定图；
- 用户自己制作或已取得授权的3D模型；
- 原创手办多角度照片；
- 配色、材质、表情和动作参考；
- 权利证明、创作者授权或委托合同。

交付采用阶段确认：角色基准图 → 设备模拟预览 → 首个动作 → 完整动作包。

### C. 想要的IP还未开放

这是“角色许愿”而不是生成订单。

用户可以：

- 搜索并提交希望上线的角色；
- 选择具体作品、角色和最想要的功能；
- 关注授权进度；
- 加入候补名单；
- 在角色上线后获得通知或早鸟权益。

平台不得暗示“投票达到数量就一定获得授权”。用户上传的图片仅用于帮助识别请求时，应尽快删除，不进入AI制作流程。

## 4. 首页信息架构

### 首屏

标题：**打开角色之门，让TA来到你的桌面**

副标题：选择正版角色进行个性化，或提交你拥有权利的原创角色。角色会经过专业制作、设备适配和人工质检。

主按钮：`唤醒一个角色`

次按钮：`看看别人如何定制`

### 首屏下方三张卡片

1. **选择正版角色**  
   从已授权角色开始，几分钟内完成造型和行为配置。  
   按钮：`进入正版角色库`

2. **带来我的原创角色**  
   上传设定图、模型或原创手办，由AI与专业制作人员共同完成。  
   按钮：`创建原创角色`

3. **许愿一个角色**  
   找不到喜欢的IP？告诉我们希望谁进入角色之门。  
   按钮：`提交角色愿望`

不要使用“上传任意动漫角色”“一键复刻喜欢的IP”等文案。

## 5. 核心体验流程

```text
进入角色之门
  → 搜索或说明角色来源
  → 系统分流与可行性判断
  → 选择形象基准
  → 配置性格与行为
  → 选择动作、音乐和记忆
  → 查看设备模拟预览
  → 查看交付物、许可、价格和时间
  → 授权确认与付款
  → AI制作 + 人工修复
  → 分阶段确认
  → 角色降临设备
  → 进入角色主页继续成长
```

## 6. “角色来源”分流页

标题：**这位角色来自哪里？**

选项：

- `Hildors正版角色库`
- `我原创或拥有完整权利的角色`
- `我购买的实体手办`
- `我喜欢的游戏或动漫角色`
- `公版故事角色的原创设计`
- `我不确定`

即时反馈：

| 用户选择 | 下一步 |
|---|---|
| 正版角色库 | 进入授权范围内的角色配置器 |
| 原创/完整权利 | 上传素材并进行权利声明 |
| 实体手办 | 先识别IP；自有原创进入定制，第三方IP进入正版匹配或许愿 |
| 喜欢的游戏/动漫角色 | 搜索授权角色；未签约则进入许愿池，不接受付款 |
| 公版再设计 | 选择原始公版来源并声明未复制现代版本 |
| 不确定 | 免费预审，不要求先付款 |

## 7. 正版角色配置器

采用“可选项配置”，而不是自由Prompt。

### 第一步：选择角色版本

- 官方经典版；
- 节日版；
- 舞台版；
- 已购买服装；
- 限定版。

每个选项展示`授权可用`标签，不能使用的组合直接隐藏或解释原因。

### 第二步：选择桌面性格

用行为表达，不要求用户写人格Prompt：

- 活力：安静 / 均衡 / 活跃；
- 主动频率：低 / 中 / 高；
- 待机气质：可爱 / 酷 / 优雅 / 搞怪；
- 互动距离：收藏展示 / 日常陪伴；
- 夜间模式：安静待机 / 完全休眠。

这些选项映射到预制视频池和播放策略，不承诺模型具有真实人格。

### 第三步：组装第一套行为包

最低可用组合：

- 1个初次见面；
- 3个待机动作；
- 1个招牌动作；
- 1个唱跳或音乐动作；
- 1个低频惊喜动作。

页面持续显示包大小、设备空间和预计安装时间。

### 第四步：建立羁绊

- 设备内昵称；
- 用户希望被如何称呼（仅使用许可词库或本地文本）；
- 纪念日；
- 喜欢的动作；
- 是否开启陪伴天数和纪念动作。

## 8. 原创角色创建器

### 上传不是第一步

先让用户选择输入类型：

- `角色设定图`
- `原创手办照片`
- `3D模型`
- `只有一个概念`

随后展示对应素材清单和价格区间，减少上传后才发现不可制作的挫败。

### 素材质量反馈

自动检查后使用可操作反馈：

- 缺少背面：`背部服装目前无法确认，补充背面图可减少AI猜测。`
- 手办反光：`表面高光遮住了纹理，请在柔和光线下补拍一张。`
- 多个角色：`请选择要进入角色之门的一个角色。`
- 疑似第三方IP：`这个形象可能来自现有作品，我们先检查是否有可用的正版版本。`
- 细节冲突：`不同图片中的服装细节不一致，请选择主要版本。`

### 角色基准确认

用户先确认“角色身份证”，包括：

- 正面、侧面、背面；
- 身高比例和头身比；
- 标志性色彩；
- 必须保留的配件；
- 禁止AI改动的细节；
- 可由制作人员合理补全的部分。

确认之后再制作动作，避免每个视频中的角色长相漂移。

## 9. 个性手办专用体验

手办路径应突出“扫描收藏品”，但不要宣称仅靠几张照片就能精确3D扫描。

拍摄引导：

1. 放在光线均匀、背景单一的位置；
2. 按轮廓引导拍摄前、后、左、右和两个斜角；
3. 补拍脸部、服装纹理、武器和底座；
4. 选择是否保留手办材质感、关节感和底座；
5. 选择“活过来”或“保持收藏品质感”。

两种产品结果：

- **活化手办**：保留造型，将关节和衣摆重构为可自然运动的角色；
- **数字陈列**：保留雕塑、树脂或玩具质感，以旋转、呼吸灯、轻微动作展示为主。

第三方IP手办只能在平台已有相应数字化授权时制作；购买凭证只能证明实体商品来源，不能替代数字改编授权。

## 10. 设备模拟预览

付款前必须让用户看到接近真实设备的预览，而不是普通全屏视频：

- P20/P11实际显示比例和安全区；
- 黑场环境和正常桌面光线两种效果；
- 角色在设备中的实际高度；
- 快速动作可能产生的拖影提示；
- 透明、发光、细线和深色服装的显示风险；
- 文件大小、设备空间和传输时间估计。

预览标记为`效果模拟`，最终交付仍需真机质检。

## 11. 订单与人工协作

对用户只展示责任清晰的阶段，不展示内部工具混乱：

```text
可行性检查
  → 角色基准制作
  → 用户确认形象
  → 动作制作
  → 设备适配与人工修复
  → 真机质检
  → 用户验收
  → 安装到设备
```

状态页需要显示：当前阶段、下一步、预计完成时间、是否需要用户操作、剩余修改次数和费用变化。

修改规则：

- 角色与已确认基准不一致：免费修复；
- 画面破损、闪烁、穿模或设备播放异常：免费修复；
- 用户在确认后更换服装、角色版本、动作或用途：重新报价；
- 正版IP修改超出品牌规范：不制作，并给出可选替代项。

## 12. 角色护照

每个角色创建一个长期主页：

- 角色来源和权利标签；
- 官方/原创/公版再设计标识；
- 当前形象基准版本；
- 已拥有动作、服装和音乐包；
- 当前设备和安装状态；
- 陪伴天数、纪念日和已解锁事件；
- 可继续购买或委托的新动作；
- 授权地区、可分享范围和下载规则。

角色护照是定制业务从“一次订单”转向“持续角色服务”的核心资产。

## 13. 权利提示的体验方式

不要一进入页面就展示长篇法律条款。采用渐进式提示：

1. 入口卡片说明“仅支持正版或有权使用的角色”；
2. 识别角色来源后解释为什么可做、限制做什么；
3. 付款前展示一页简明许可摘要；
4. 完整条款作为可展开内容；
5. 高风险或证据不足项目进入人工预审。

许可摘要至少回答：

- 我可以在几台设备使用？
- 能否保存、重新下载和迁移？
- 能否发到社交平台？
- 能否在门店、直播或展会使用？
- 能否继续委托其他动作？
- IP授权到期后已交付内容如何处理？

## 14. 失败与等待体验

### IP未开放

不要只显示“版权原因无法制作”。改为：

> 这位角色目前还没有进入Hildors正版角色库。你可以提交愿望、关注授权进度，或选择相似气质的Hildors原创角色；我们不会在未获得许可前收取制作费。

### 素材不足

保存已完成步骤，给出具体补拍任务；用户补件后回到原节点。

### AI结果不稳定

系统转人工评估，不要求用户重复付费抽取结果；超出套餐能力时先报价再继续。

### 设备暂未连接

允许先完成制作和进入素材库，连接设备后继续安装，不阻塞订单交付。

## 15. MVP范围

### P0：验证“角色进入设备”的核心价值

- 三路径入口与来源分流；
- 3个官方/自有角色的配置器；
- 原创角色人工预审申请；
- IP许愿池；
- 固定动作包选择；
- 设备模拟预览；
- 角色护照；
- 订单时间线；
- 真机安装和首次唤醒仪式。

P0不开放“上传任意动漫图立即生成并付款”。

### P1：提高个性化与复购

- 原创手办多角度拍摄引导；
- 角色基准分阶段确认；
- 服装、动作和节日扩展包；
- 陪伴天数和纪念事件；
- 许愿角色上线通知；
- 创作者接受授权范围内的动作委托。

### P2：增强互动

- 音乐状态和节奏联动；
- 更深的角色记忆；
- 多角色同台；
- 受控自然语言配置；
- 更多原创角色自助生成能力。

## 16. 首轮体验实验

### 实验一：入口表达

- A：`定制你的专属全息角色`
- B：`打开角色之门，让TA来到你的桌面`

观察进入率、完成来源选择率和用户对产品能力的理解。

### 实验二：预览时机

- A：配置完成后再预览；
- B：每选择一个动作，设备模拟即时更新。

观察完成率、预览播放次数和付款率。

### 实验三：人工服务表达

- A：`AI生成`
- B：`AI制作 + 专业人工修复 + 真机质检`

观察信任度、价格接受度和退款预期。

### 实验四：IP未开放承接

- A：只显示不可制作；
- B：许愿 + 上线通知 + 原创替代推荐。

观察许愿转化、通知订阅和流失率。

## 17. 关键指标

主漏斗：

```text
进入定制首页
→ 完成角色来源选择
→ 找到可制作路径
→ 完成形象/行为配置
→ 播放设备预览
→ 查看报价
→ 付款
→ 确认角色基准
→ 完成交付
→ 成功安装并首次播放
→ 30天内购买或委托第二个内容
```

重点指标：

- 可制作路径匹配率；
- IP搜索无结果率和许愿率；
- 素材一次通过率；
- 设备预览到付款转化率；
- 角色基准一次确认率；
- 人工返工时间和单单毛利；
- 真机安装成功率；
- 首次唤醒完成率；
- 30天扩展包或新动作复购率；
- 版权原因拒单率和用户投诉率。

## 18. 最终判断

这个板块最有价值的不是“让用户无限生成”，而是同时解决三个问题：

1. 用户怎样合法地获得真正喜欢的角色；
2. 角色怎样在全息设备上表现得稳定、好看、有生命感；
3. 一次定制怎样沉淀成可长期成长和持续消费的角色资产。

因此，首发体验应以“正版角色配置器 + 原创角色人工定制 + IP许愿池”为骨架，以“角色护照”和“首次唤醒仪式”完成情感闭环。
