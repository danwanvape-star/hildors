# 用户身份与角色包权益基础

此阶段是本地后端基础，不是已上线的账号系统。没有注册、密码、短信、第三方登录或支付接口；App仍使用上一阶段的只读目录。

- 内部可信代码创建用户、签发最多24小时的随机会话；数据库只保存令牌SHA-256摘要。
- `GET /v1/me`：读取当前用户。`DELETE /v1/me/session`：注销当前会话。
- `GET /v1/me/entitlements`：只返回令牌所属用户的角色包权益，不接受客户端指定用户身份。
- 用户会话和管理员令牌相互隔离。权益由内部可信代码授予或撤销，不开放客户端自行领取接口。
- 权益以角色包为单位，播放列表仍以包内视频为单位。收藏、下载缓存、内容权益和设备文件不能混为一谈。
- 下架保留权益记录，但标记不可用；撤销后也不可用。所有结果明确关闭云端下载及硬件就绪能力。
- 正式登录接入前需完成身份供应商验证、HTTPS、限流、会话清理、账号停用和生产审计；付费权益须由验证过的订单/支付回调授予。

测试覆盖用户隔离、伪造用户参数、管理员/用户权限隔离、注销、下架与撤销。没有真机登录或支付验收。
