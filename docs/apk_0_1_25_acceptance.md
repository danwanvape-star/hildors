# 0.1.25 网格藏品与我的角色体验

版本：0.1.25+26。实际构建与校验信息见 releases/安装包说明.md。

## 本轮检查

1. 藏品 → 内容库：三列方形封面；出处、形式、题材及搜索共同筛选；无结果可清除筛选。
2. 藏品 → 我的角色：不出现重复“我的收藏”标题；普通手机三列，窄屏或大字号两列。
3. 我的角色：已有视频时选择包内具体视频，再选择日常展示或音乐联动，加入待处理区；不覆盖已有条目，重复选片去重。
4. 播放列表 → 添加视频 → 从我的角色选择：进入相同网格，选片后返回当前列表，不再另问目标列表。
5. 未收藏的公共 Demo 不混入我的角色；概念图角色和未交付定制内容不冒充可导入视频。
6. 手机导入仍直接进入播放列表待处理区，不单独建立本地视频库。

## 边界

- 公共 Demo 保留于内容库；目前概念角色尚无真实包内视频，直接导入按钮禁用。
- 转码和硬件上传仍等待厂家接口，本轮是界面与本地流程体验。
- 使用现有测试签名；未进行手机安装启动及硬件联调实测。
