# Hildors Custom Video Service — US/EU UX Copy Draft

> Draft for product and design implementation. This is not final legal language. Local counsel must review the applicable version for each launch country/state, especially withdrawal rights, subscription renewals, biometric processing, minors, international transfers, and AI-content disclosures.

## 1. Copy standards

- Say what the user receives before asking for data.
- Use plain, specific language instead of “I agree to everything.”
- Separate required acknowledgements from optional choices.
- Never preselect optional consent.
- Do not promise “100% likeness,” “guaranteed results,” “unique output,” “zero retention,” or “fully automated.”
- Refer to “AI-assisted creation with human review,” not a specific model vendor.
- Keep subscription price, billing frequency, renewal date, and cancellation control adjacent to the purchase button.
- Show the current policy version and allow the user to reopen what they accepted.

## 21. Error and support copy

Every error explains what happened, whether data is safe, and what the user can do.

| Event | Copy |
|---|---|
| Upload interrupted | Upload paused. Completed parts are saved. Reconnect and select Resume. |
| Production quality failure | The current result did not meet our delivery standard. A production specialist will review it; you do not need to place a new order. |
| Provider policy block | We cannot process this request as submitted. No final content has been delivered. Review the reason and available next steps. |
| Download mismatch | The downloaded file is incomplete and cannot be transferred. Delete this local copy and download it again. |
| Device disconnected | The device connection ended. The verified file remains on your phone. Reconnect to continue. |
| Deletion pending | Your deletion request is in progress across the systems listed here. We will notify you when verification is complete. |
| Deletion exception | We deleted the production files listed here. We retained limited records for {approvedReason} until {date}. Contact Privacy Support to challenge this result. |

## 22. Localization requirements

- Provide privacy, consent, payment, withdrawal, cancellation, and support copy in the language used to sell the service.
- Do not rely on English-only legal links in a localized checkout.
- Dates use unambiguous localized formats and include time zone where relevant.
- Prices show currency and applicable tax treatment before purchase.
- The translated version must preserve whether an item is required, optional, or market-specific.
- Legal translations receive version IDs independent from general UI translation releases.
